# 배구지수 2026 학교별 통계 · 정오 자동연동

현재 비공개 학교별 통계 파일: `2026 배구지수 학교별 통계 · 비공개 집계 MASTER (정오 자동연동 준비)`

## 최초 1회 설치 (수동 필수)

1. [2026 배구지수 본조사 응답 시트](https://docs.google.com/spreadsheets/d/1T_rEz1LqX97pC9gOv33SRmspK2IizTU3wFtxA8P1pC4/edit)를 소유자 또는 편집자 권한으로 연다.
2. **확장 프로그램 → Apps Script** 를 연다.
3. `scripts/beagu-2026-noon-sync.gs`의 전체 내용을 복사하여 기본 `Code.gs`에 붙여넣는다. 기존 코드가 있다면 먼저 백업하고 함부로 덮어쓰지 않는다.
4. Apps Script의 **프로젝트 설정 → 스크립트 속성**에서 `SUPABASE_PUBLISHABLE_KEY`를 추가한다. 값은 GitHub `js/supabase-config.js`의 공개용 publishable/anon 키를 사용한다. **service_role 키를 입력하지 않는다.**
5. `refreshBeagu2026Stats`를 한 번 수동 실행하고 Google 계정 권한을 승인한다.
6. [비공개 집계 MASTER](https://docs.google.com/spreadsheets/d/1I9SXXmOCnyeWP3RjoBHW5Tfvg0RpgR4RjnEVoxZvpp8/edit)의 `학교별_집계_내부`, `학교매칭_보류`, `정오_실행로그` 탭을 확인한다.
7. `setupDailyNoonTrigger`를 **한 번** 실행하여 시간 기반 트리거를 생성한다. Apps Script의 실행/트리거 탭에서 등록 여부 확인.

## 일정 및 동작

- Google Apps Script 설치형 트리거: `Asia/Seoul` 매일 12시 부근(일반적으로 ±15분; 정확한 분 단위 실행은 보장되지 않음).
- 원본 응답에서 타임스탬프·B01/B02/B03·Q01~Q13 열만 확인한다. **2026-11-01 이전의 사전 제출 자료는 자동 제외**하며, 날짜를 식별할 수 없는 응답은 보류한다.
- 국내 17개 시도뿐 아니라 `재외한국학교` 지역의 국가별 학교도 식별 대상으로 지원한다.
- `schools`의 시도·교육지원청·학교 이름이 **모두 일치**해야 자동 매칭한다. 동명학교를 학교명만으로 합치지 않는다.
- 선택지의 정확한 문자열을 현재 Supabase 내부 채점표에 맞춰 0~100점으로 변환한다.
- 비공개 시트에 학교별 13문항 평균, 내부 참고 평균, 매칭 실패 기록 및 실행 로그를 갱신한다.
- **원자료 개별 응답, 타임스탬프, 자유서술은 비공개 집계 시트에 복사하지 않는다.**
- 공개되지 말아야 할 학교별 응답 횟수는 내부 집계의 `원자료_행수_내부`에만 보관하고 웹/API로 반환하지 않는다.

## 공개와의 연결에 관한 중요한 경계

이 스크립트는 **학교별 내부 통계를 갱신하지만 웹사이트의 공개 API나 Supabase 승인 상태를 자동으로 변경하지 않는다.**

현재 2026년 수직성 Q01~Q13 코드북은 `verified=false`, `beagu_release_metrics_v2`에는 승인 값이 없으므로 다음 항목이 선행되어야 실제 Lv.1·Lv.2에 값이 보인다.

1. Q01~Q13 문항 원문·선택지·방향·공식 2026 백분위 산식 검증.
2. 인구·표본 및 학교별 민감 문항 조합에 대한 재식별 위험 검토.
3. Supabase의 승인된 공개지표 `beagu_release_metrics_v2` 생성(필드별 검토 승인 후).
4. 서버의 기존 `releaseMetrics` 정책에 따라 Lv.1은 2026 백분위 + Q01~Q13만 제공하고 Lv.2는 나머지 공개 승인 자료를 제공.

**검수 전 임시 평균은 공식 배구지수 백분위가 아니다.** 승인 절차를 우회해 웹에 직접 게시하지 말 것.

## 장애 및 품질 점검

- Google Forms 문항·보기 변경: 코드가 알 수 없는 보기를 만나면 오류로 중지해 기존 통계를 보존한다.
- 본조사 전 시범 응답은 공식 학교별 응답 수에 포함하지 않는다. 기존 시범 입력은 비공개 MASTER에서 `PRELAUNCH_EXCLUDED`로 표시한다.
- 학교 매칭 불일치: `학교매칭_보류` 시트에 쌓고, 해당 학교 통계는 자동 게시하지 않는다.
- 원자료 시트 접근 권한 분실/공개키 누락: `정오_실행로그`에 기록하며 기존 결과는 보존한다.
- 새로 설치한 트리거의 실행 성공 여부는 반드시 **Apps Script → 실행**에서 확인한다.
