# 배구지수 2026 학교별 통계 · 정오 자동연동

## v1.12.06 후보 — 15분 통합 집계 (미적용)

이 절은 아래의 과거 제출/정오 트리거 설명을 대체한다. 운영 적용·설치는 별도 승인 후 소유자가 수행하며, 후보 코드만으로 기존 트리거가 변경되지 않는다.

- Google Forms 원본 응답 저장은 그대로 유지한다. 기존 폼 제출 핸들러는 전체 재집계를 실행하지 않는다.
- `installBeagu2026Sync`는 이 파이프라인의 기존 제출/정오/중복 집계 트리거를 하나의 `runBeagu2026QuarterHour` (15분) 트리거로 교체한다. 다른 목적의 트리거 및 VI13 요청 폴러는 유지한다. 실행 중이면 예약 집계는 다음 주기에 넘긴다.
- 문항 집계 전송은 서버 성공 응답을 받은 정제된 집계의 SHA-256과 비교한다. 스냅샷 시각만 제외하고 다른 데이터는 비교하며 실패/모호한 응답은 성공 기록을 남기지 않는다. 직접 문항 재집계 호출 및 마지막 성공 전송 24시간 경과 후에는 동일 자료도 다시 전송한다. 비공개 검수 시트와 나머지 집계 경로는 유지한다.
- 실제 트리거 목록은 설치자별로 다를 수 있으므로 소유자가 Apps Script의 트리거/실행 탭에서 기존 핸들러와 중복 여부를 먼저 확인해야 한다. 원본·공개 조건·서버 권한은 수정하지 않는다. 15분은 예약 간격이지 최신성 보장이 아니다.

현재 비공개 학교별 통계 파일: `2026 배구지수 학교별 통계 · 비공개 집계 MASTER (정오 자동연동 준비)`

## 최초 1회 설치 (수동 필수)

1. [2026 배구지수 본조사 응답 시트](https://docs.google.com/spreadsheets/d/1T_rEz1LqX97pC9gOv33SRmspK2IizTU3wFtxA8P1pC4/edit)를 소유자 또는 편집자 권한으로 연다.
2. **확장 프로그램 → Apps Script** 를 연다.
3. `scripts/beagu-2026-noon-sync.gs`를 `Code.gs`에, `scripts/beagu-2026-mbti-review-sync.gs`를 별도 `MBTI_Review.gs`에 반영한다. 기존 Apps Script 코드와 트리거를 먼저 백업한다. 같은 이름의 함수를 중복 정의하지 않는다.
4. Apps Script의 **프로젝트 설정 → 스크립트 속성**에서 `SUPABASE_PUBLISHABLE_KEY`를 추가한다. 값은 GitHub `js/supabase-config.js`의 공개용 publishable/anon 키를 사용한다. **service_role 키를 입력하지 않는다.**
5. 테스트용 실제 응답을 새로 만들지 않는다. 스크립트 함수 `refreshBeagu2026AllPrivateStats`를 한 번 실행해 이미 있는 원본 응답 2행을 재집계하며 Google 계정 권한을 승인한다. 첫 사전 응답은 집계에서 제외한다.
6. [비공개 집계 MASTER](https://docs.google.com/spreadsheets/d/1I9SXXmOCnyeWP3RjoBHW5Tfvg0RpgR4RjnEVoxZvpp8/edit)의 `학교별_집계_내부`, `학교매칭_보류`, `정오_실행로그` 탭을 확인한다.
7. `SUPABASE_PUBLISHABLE_KEY`, `BEAGU_2026_INGEST_TOKEN`(서버와 동일한 비밀 토큰)을 스크립트 속성에서 확인하고 `installBeagu2026Sync`를 **한 번** 실행한다. 설치되는 두 트리거는 `onBeagu2026FormSubmitted`(폼 제출 직후), `refreshBeagu2026AllPrivateStats`(매일 정오 백업)이다. 두 집계(Q01~Q13, Q14~Q17)가 같은 트리거로 동작한다. Apps Script 실행/트리거 탭에서 두 개의 설치·성공 여부를 확인한다.

## 설문 제출 직후 자동 집계 (최초 설치 후 자동 운영)

- 위 1회 설치가 완료되면 이후 응답은 `onBeagu2026FormSubmitted`가 자동으로 비공개 집계한다. **매 응답마다 ChatGPT에 등록 명령을 할 필요가 없다.** 초기 설치는 Google Apps Script 소유자의 OAuth 승인이 필요하므로 GitHub 커밋만으로 실제 트리거가 설치되지 않는다.
- Google Forms에서 실제 응답이 제출될 때 `onBeagu2026FormSubmitted`가 실행되어 비공개 MASTER를 다시 집계합니다. Google 처리 및 Apps Script 실행 지연이 있어 '즉시'를 보장할 수는 없습니다.
- 매일 정오 백업 트리거 `refreshBeagu2026AllPrivateStats`도 함께 실행된다. 최초 설치 함수는 기존 독립 집계·MBTI 백업 트리거를 정리해 중복 실행을 방지한다.
- 최초 설치 전에 **현재 트리거 목록·실행 로그를 점검**해 동일 목적 트리거가 중복되지 않게 하세요.
- **학교별 Q01~Q13 채점과 Q14~Q17 학교문화 자료는 내부 집계만 자동 갱신한다.** 전국 누적 참여횟수·참여학교 수도 별도 보호된 전송 경로로 동기화한다. 2026년 학교별 상세조회에 결과가 표시되려면 데이터 검증, 동의·재식별 검토, 수동 공개 승인 후 24시간 지연을 통과해야 한다.
- 설치되지 않은 트리거가 실제로 작동한다고 표시하거나, 현재 승인된 결과가 있다고 주장하지 않습니다.

## 일정 및 동작

- Google Apps Script 설치형 트리거: `Asia/Seoul` 매일 12시 부근(일반적으로 ±15분; 정확한 분 단위 실행은 보장되지 않음).
- 원본 응답에서 타임스탬프·B01/B02/B03·Q01~Q13 열만 확인한다. **2026-11-01 이전의 사전 제출 자료는 자동 제외**하며, 날짜를 식별할 수 없는 응답은 보류한다.
- 국내 17개 시도뿐 아니라 `재외한국학교` 지역의 국가별 학교도 식별 대상으로 지원한다.
- `schools`의 시도·교육지원청·학교 이름이 **모두 일치**해야 자동 매칭한다. 동명학교를 학교명만으로 합치지 않는다.
- 선택지의 정확한 문자열을 현재 Supabase 내부 채점표에 맞춰 0~100점으로 변환한다.
- 비공개 시트에 학교별 13문항 평균, 내부 참고 평균, 매칭 실패 기록 및 실행 로그를 갱신한다.
- **원자료 개별 응답, 타임스탬프, 자유서술은 비공개 집계 시트에 복사하지 않는다.**
- 학교별 응답 횟수는 내부 집계의 `원자료_행수_내부`에만 보관하고 홈 화면/API에는 개별 학교 정보를 노출하지 않는다. 2023–2025년 자료를 대조한 **전국 신규 참여학교 수**만 누적 집계한다.

## 공개와의 연결에 관한 중요한 경계

이 스크립트는 **학교별 내부 통계를 갱신하지만 웹사이트의 공개 API나 Supabase 승인 상태를 자동으로 변경하지 않는다.**

현재 2026년 수직성 Q01~Q13 코드북은 `verified=false`, `beagu_release_metrics_v2`에는 승인 값이 없으므로 다음 항목이 선행되어야 실제 Lv.1·Lv.2에 값이 보인다.

1. Q01~Q13 문항 원문·선택지·방향·공식 2026 백분위 산식 검증.
2. 인구·표본 및 학교별 민감 문항 조합에 대한 재식별 위험 검토.
3. Supabase의 승인된 공개지표 `beagu_release_metrics_v2` 생성(필드별 검토 승인 후).
4. 서버의 기존 `releaseMetrics` 정책에 따라 Lv.1은 2026 백분위 + Q01~Q13만 제공하고 Lv.2는 나머지 공개 승인 자료를 제공.

**검수 전 임시 평균은 공식 배구지수 백분위가 아니다.** 승인 절차를 우회해 웹에 직접 게시하지 말 것.

## 장애 및 품질 점검

- Google Forms 문항·보기 변경: Q01~Q13의 기타·미등록 보기는 점수로 추측하지 않고 `2026_기타응답_검수대기`에 **원본 행번호·학교ID·문항 코드만** 기록한다. 해당 점수는 결측 처리하고 같은 응답의 나머지 정상 문항 및 다른 학교 집계는 계속 진행한다. 원문·자유서술은 MASTER에 복사하지 않는다. Q01~Q50의 미등록 보기는 별도로 `2026_문항별_검수대기`의 검증불가수로 기록되며 해당 결과는 공개 승인 대상에서 제외한다.
- 본조사 전 시범 응답은 공식 학교별 응답 수에 포함하지 않는다. 기존 시범 입력은 비공개 MASTER에서 `PRELAUNCH_EXCLUDED`로 표시한다.
- 학교 매칭 불일치: `학교매칭_보류` 시트에 쌓고, 해당 학교 통계는 자동 게시하지 않는다.
- 원자료 시트 접근 권한 분실/공개키 누락: `정오_실행로그`에 기록하며 기존 결과는 보존한다.
- 새로 설치한 트리거의 실행 성공 여부는 반드시 **Apps Script → 실행**에서 확인한다.

자세한 누적 통계 정의, 보호된 과거 학교 ID 조회, 수동 설치 상태는 `docs/2026-live-aggregate-setup.md`를 참조합니다.

- Supabase Cron `beagu-2026-private-auto-quality-check`: **15분 주기 활성**. 설문 이전 응답, 학교 매칭, 문항 수, 검증된 코드북, 고유 응답자 및 개인정보 검토, 소표본 위험을 점검한다. 검수 사유는 `beagu_private.beagu_2026_auto_review_status`에서 조회한다.
- 2026-11-19 초기 QA 실행: 보유 기록 2개 학교 평가. 1개 학교 사전응답 제외, 1개 학교 학교정보 불일치 검수대기. **자동 공개 승인은 0건**.
- **주의:** 위 서버 작업이 완료돼도 원본 Google Apps Script 실제 설치를 뜻하지 않는다. 원본 스프레드시트의 Apps Script에서 최신 소스를 반영하고 `installBeagu2026Sync`를 최초 한 번 실행해야 신규 Google Forms 응답이 자동 전송된다.
- 설립유형 불일치, 공개 동의 근거 없음, 고유 응답자 검증 누락, 개인정보 심사 미완료, 학교별 소표본 위험, 코드북 미검증이면 **학교별 공개 금지**. 자동 기술 검수는 법적 동의 또는 재식별 위험 판단을 대신하지 않는다.
- 전국 누적 참여횟수는 종전대로 보호된 서버 경로에서 자동 갱신할 수 있지만, 학교별 2026 수치와 자유서술은 이 과정에서 승인되지 않는다.

## 2026-11-19: 학교별 Q01~Q50 공개 연결

최신 `beagu-2026-noon-sync.gs` 전체를 **Code.gs**, `beagu-2026-mbti-review-sync.gs` 전체를 **MBTI_Review.gs**에 저장한다. 파일은 여전히 두 개다. Code.gs에는 Q01~Q50 집계기가 포함되어 있다. 기존 코드를 백업하고 동일 함수의 중복 선언을 피한다.

`refreshBeagu2026AllPrivateStats`는 Q01~Q50 빈도 집계 → Q01~Q13 점수 및 검수용 건수 → Q14~Q17 학교문화 검수대기 집계를 실행한다. 전체 집계를 원본에서 다시 계산하며 Q51 이후 자유서술 응답 셀은 읽지 않는다. Q01~Q13의 내부 참고평균을 공식 백분위로 간주하지 않는다.

- 신규 비공개 전송: `beagu-2026-results-ingest`. 기존 `BEAGU_2026_INGEST_TOKEN`을 사용한다. 키를 새로 만들거나 교체하지 않는다.
- 전송값: 학교 ID, 응답건수, 매칭상태, 닫힌 보기별 빈도, 시간 문항의 분 단위 합계. 개별 응답 조합·학교명·개인정보·기타 자유입력은 전송하지 않는다.
- 기존 QA endpoint는 건수 전용으로 유지한다.
- MASTER의 `2026_문항별_검수대기`에 비공개 결과를 저장한다.
- Supabase의 `beagu_2026_results_snapshot`은 RLS로 익명·일반 인증 사용자의 직접 접근을 차단한다.
- 검수자가 `beagu_2026_approve_results`로 **해당 내용 해시**를 승인해야 한다. 원본·채점, 학교, 중복, 실제 동의, 소표본, 재식별, 과거자료 결합 위험의 근거를 각각 기록한다. 근거가 없으면 승인하지 않는다.
- 승인 후 24시간이 지난 결과만 인증 API가 제공한다. 학교별 응답건수·빈도분포는 공개하지 않고 단일선택 최빈값(동률 포함), 복수선택 항목, 시간 평균을 제공한다.
- 내용이 달라지면 승인을 해제하고 재검토한다. 동일 결과 재전송은 승인시각을 변경하지 않는다. 원본에서 제거된 학교는 공개 대상에서 제거한다. 늦게 도착한 이전 스냅샷은 거부한다.
- `installBeagu2026Sync()`는 Google 권한 승인과 기존 두 스크립트 속성 설정 후 한 번 실행한다. 트리거는 제출 시와 한국시간 정오 두 개만 사용한다.

개발 시 `node scripts/build-2026-results.mjs`로 Code.gs 내 생성 부분과 서버 카탈로그를 함께 갱신한다. `node tests/2026-question-results-pipeline.mjs`로 보기 검증·개인정보 전송 차단·스크립트 구문을 확인한다.

## 2026-11-19 기타 응답 검수 정책

- 원본 응답은 수정하지 않는다. Q12·Q13의 '기타' 직접 입력이나 코드북에 없는 Q01~Q13 답변은 해당 문항만 결측 처리하고 `2026_기타응답_검수대기`에 원본 행번호를 남긴다.
- 원문은 원본 Google Forms 응답 시트에만 보관한다. 검수용 MASTER에 복사하지 않으며, 공개 서버에 전송하지 않는다.
- Q01~Q50의 비공개 학교별 빈도 집계는 기존 `2026_문항별_검수대기`와 서버 집계로 계속 유지한다. 공개 승인은 별도다.
- **운영 주의:** GitHub의 Code.gs 수정만으로 구글 Apps Script 프로젝트에 자동 반영되는 것은 아니다. 소유자가 최신 Code.gs를 저장하고 트리거 실행 성공을 확인해야 한다.

## 전체 집계와 공개 승인

- 전체 실행에서 원본의 Q50까지와 운영 학교 목록을 한 번 읽고, 동일한 자료로 세 가지 비공개 집계를 계산한다. 실행 잠금으로 제출 트리거와 정오 트리거가 서로의 결과를 덮어쓰지 않게 한다.
- 학교별 공개는 운영자가 비공개 집계의 대상 해시, 승인자, 동의 및 위험 검토 증빙을 지정해야 시작된다. 정확한 해시의 승인부터 24시간이 경과해야 조회할 수 있다.
- 홈의 전국 참여 누계는 기존 참여 현황 집계로, 학교별 조사 결과 공개와 독립적으로 갱신된다.
