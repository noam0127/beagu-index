관리자 계정 등록

미리 승인된 이메일의 소유자만 관리자 권한을 활성화할 수 있습니다.

계정 상태를 확인하는 중입니다.

1. 계정 만들기

승인된 이메일 주소로 직접 비밀번호를 등록합니다. 이메일 인증 후 이 페이지로 돌아와 로그인하세요.

2. 이메일 확인 후 로그인

메일함의 Supabase 계정 인증을 완료한 뒤, 등록한 비밀번호로 로그인합니다.

3. 관리자 권한 연결

로그인되었습니다. 이메일 인증까지 마쳤다면, ChatGPT 대화에서 ‘관리자 가입 완료’라고 알려 주세요. 인증 완료 계정과 사전 승인된 이메일 주소가 일치하는지 확인한 뒤 관리자 권한을 연결합니다. 비밀번호는 전달하지 않아도 됩니다.

관리자 로그인 화면으로 이동

안내: 관리자 계정은 기존 레벨0·1·2 참여 인증과 분리되어 있습니다. 가입 비밀번호나 이메일 인증 링크를 ChatGPT 대화에 입력하지 마세요. 관리자 권한 연결 후 관리자 화면에서 인증 앱(TOTP) 2단계 인증을 설정해야 합니다.
