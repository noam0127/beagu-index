관리자 계정 등록

미리 승인된 이메일의 소유자만 관리자 권한을 활성화할 수 있습니다.

계정 상태를 확인하는 중입니다.

1. 계정 만들기

승인된 이메일 주소로 직접 비밀번호를 등록합니다. 이메일 인증 후 이 페이지로 돌아와 로그인하세요.

2. 이메일 확인 후 로그인

메일함의 Supabase 계정 인증을 완료한 뒤, 등록한 비밀번호로 로그인합니다.

3. 관리자 초대코드 확인

별도로 발송한 관리자 등록 메일의 일회용 코드를 입력하세요. 다른 사람에게 공유하지 마세요. 코드는 재사용할 수 없습니다.

안내: 관리자 계정은 기존 레벨0·1·2 참여 인증과 분리되어 있습니다. 계정 비밀번호나 인증코드를 ChatGPT 대화에 입력하지 마세요. 권한 활성화 후 관리자 화면에서 인증 앱(TOTP) 2단계 인증을 설정해야 합니다.

이미 관리자 계정을 등록했다면 로그인으로 이동
