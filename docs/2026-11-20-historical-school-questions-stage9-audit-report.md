## 2. 원본과 공식 학교 식별 근거

### 충남 신리초(아산, `8181034`, 2023)

2023년 원본 설문에서 입력 시도 `충남`, 학교명 `신리초등학교`인 응답은 있지만 교육지원청 또는 불변 학교 ID가 존재하지 않는다. 과거 공개 편집본은 이 데이터를 **아산 신리초**로 집계하였고, 앞선 10개 문항의 가공 점수가 실제 원본의 평균과 일치한다는 사실을 8차에서 검증했다.

학교알리미는 아산 신리초를 아산교육지원청 학교로 확인한다:  
https://www.schoolinfo.go.kr/ei/ss/Pneiss_b01_s0.do?SHL_IDF_CD=c939e159-196c-47bd-a9e4-759d93770b56

2023년 당시 홍성에도 `신리초등학교`라는 이름의 별도 학교가 있었음을 확인한다(설립 2013.03.01):  
https://statnorth.kr/schools/%EC%B6%A9%EB%82%A8/%ED%99%8D%EC%84%B1%EA%B5%B0/%EC%8B%A0%EB%A6%AC%EC%B4%88%EB%93%B1%ED%95%99%EA%B5%90-e11869d77a6b

따라서 공개 편집본이 예전에 아산으로 분류했다는 사실은 확인했지만, **설문 응답자의 소속을 아산으로 독립 검증하지 못했다**. 원본 교직원별 개별 응답을 임의로 아산·홍성 어느 학교에도 강제 배정하지 않는다.

판정: `SCHOOL_ID_AMBIGUOUS`, `REVIEW_BLOCKED`.

원본의 `경남 / 양산 / 삼성초등학교` 응답 2건을 Q01~Q14의 동일 문항끼리 비교했으며 **14개 문항 모두 선택값이 달라 단독 최다 선택값이 성립하지 않았다.** 각 문항의 임의 가중 평균·임의 단독 보기 생성은 중단한다.

판정: `NO_UNIQUE_MODE`, `REVIEW_BLOCKED`.

## 3. 감사 SQL에서 발견한 출처 분류 버그 및 수정

기존 `scripts/audit-historical-question-coverage-20261120.sql`은 세 복구 출처 `SOURCE_RECONCILED_DISTRICT_20261120`, `SOURCE_RECONCILED_OFFICIAL_ALIAS_20261120`, `SOURCE_RECONCILED_TYPO_20261120_STAGE7`를 `PREEXISTING`으로 잘못 묶었다.

## 4. 추가 유효성 및 보안 점검

각 항목에 검증된 Qxx 식별자, 1~180자 유효 문자열, 양수 `validRows`, 빈 `roundedDistribution` 배열이 존재하는지 확인했다. **원본 응답값·시각·학교별 응답수는 감사 결과에 출력하지 않았다.**

운영 `beagu_school_question_aggregates_v2`, `beagu_school_question_modes_supplement_v1` 테이블의 `rls_enabled=true`, `anon_can_read=false`, `authenticated_can_read=false`을 SQL에서 직접 확인했다. 모든 7,801건의 `review_status`가 `OWNER_AUTHORIZED_CLOSED_CHOICE`임을 확인했으나, 개별 동의나 소규모 셀 재식별 위험에 대한 추가 심사가 완료되었다는 뜻은 아니다.

## 5. 운영 통합검증 한계

현재 실행 환경에서 운영 도메인 `baeguindex.com` 및 Supabase Function의 직접 HTTP 접속을 시도했으나 DNS 또는 가져오기 제한으로 접속을 검증하지 못했다. 따라서 **레벨1 로그인 브라우저에서 결과를 실제 표시했다는 E2E 성공 주장은 하지 않는다**. 운영 서버 코드와 GitHub 코드가 같다는 정적 검증, DB 적합성 검증과 구분한다.

GitHub 측 Vercel 체크는 빌드 횟수 제한으로 실패를 보고했다. 이번 변경은 **감사 SQL 파일만 수정**했으며, 사이트 프론트엔드·운영 API·DB 집계는 변경하지 않았다.
