# 『나의 OO한 학급일지』 원고 개발 기준 — 다섯 동료·36화·복선 회수

## 1. 시간축과 시점

- **2027년 3월 1일(월·삼일절):** 주인공은 저경력일 경우 임용시험 공부, 중경력일 경우 육아, 고경력일 경우 명예퇴직 후 여행 중에 교감의 긴급 전화를 받는다.
- **2027년 3월 2일(화):** 3학년 **장미반**에 기간제 담임교사로 첫 출근한다. 7월까지 학급을 맡는다는 설정이다.
- **프롤로그:** 학교 선택 후 선택한 동료가 자신의 1인칭으로 첫 등교를 바라본다. 학교명·지역·승인된 공개 수치는 별도 안내 카드에만, 실제 학생이나 교직원의 사정은 포함하지 않는다.
- **주인공 설정:** 동료 시점 프롤로그가 끝난 뒤 이름·교직 경력·성별을 결정한다.
- **본편:** 제1~36화 및 선택 결과·결말 모두 주인공인 '나'의 1인칭. 주인공은 다른 사람의 마음을 알 수 없고 관찰한 행동과 들은 말로만 판단한다.
- **프롤로그 분량:** 서로 공유하는 새 학기 사건의 연속성에 각 동료의 독립적인 12장면 관점을 덧붙여 경로별 **52문단, 약 10,000자**.
- **본편 분량:** 36화 각 7문단 이상, 기본 원고 약 850~1,050자에 교육관 대립·인물별 사건·선택 복선 회수를 더한다.

## 2. 캐릭터의 신념·약점·반전

| 이름 | 취미 | 교육관과 강점 | 결함·관계 | 결말까지 회수할 상징 |
|---|---|---|---|---|
| 서지윤 | 베이스기타 | 직접 경험하며 배우는 현장 중심 수업, 학생의 표정 관찰 | 안전·일정의 구조를 가볍게 볼 때가 있고 도움을 청하기 어려움 | 네 박자·베이스 줄 → 기다리는 수업 |
| 한현우 | 『논어』·『시경』 읽기 | 말과 예의, 관계의 품격을 중시함 | 갈등을 농담이나 인용으로 피할 때가 있음 | 접힌 책갈피 → 실제로 듣는 행동 |
| 윤민서 | 중식 요리 | 이론·정확한 자료·계획과 기록, 안전·개념의 형평성 | 계획에 없는 질문과 예측 불가능한 상황에 경직됨 | 웍의 화력·두 칸짜리 조리표 → 수정 가능한 수업안 |
| 차도겸 | 실뜨기 | 손으로 배우는 협력, 조용한 사람의 참여 | 눈에 띄는 외모로 학생들의 관심을 받아 선을 정하는 데 어려움 | 파란 실·풀린 매듭 → 동의와 선택권 |
| 백태오 | 배구 | 팀의 연결과 몸의 참여를 중시하는 교사 | 승부욕 때문에 공을 못 받거나 운동을 싫어하는 아이를 놓칠 때가 있음 | 닳은 배구공·점수판 → 스스로 참여를 선택하는 팀 |

세 동료의 가치는 끝까지 같아지지 않는다. **현장학습 중심(지윤) ↔ 이론수업 중심(민서)**의 대립은 제10·13·16·19·22·26·29·30화에서 논쟁 → 사고의 위험 인식 → 수업 설계 → 공개수업의 재검토로 전개된다. 현우는 경청과 실제 행동의 사이를, 도겸은 동의와 돌봄의 사이를, 태오는 협력과 경쟁의 사이를 탐색한다.

## 4. 구현과 검증 파일

- `js/class-diary-prologue-scenes-v1.js`: 3월 1~2일 사건을 동료가 관찰한 장면 12개와 결말.
- `js/class-diary-prologue-lens-{woman,man,none,man2,man3}-v1.js`: 다섯 화자의 독립적인 관점.
- `js/class-diary-narrator-long-v3.js`: 화자별 52문단 프롤로그.
- `js/class-diary-prose-act1-v1.js` ~ `act6-v1.js`: 36화 본문·선택.
- `js/class-diary-pedagogy-v1.js`: 교육관 충돌과 통합 16장면.
- `js/class-diary-colleague-dogyeom-v1.js`, `js/class-diary-colleague-taeo-v1.js`: 실뜨기 17장면, 배구 19장면.

- `teacher-class-diary-play.html`: 학교 공개정보 → 선택 동료 프롤로그 → 나의 설정 → 1~36화.
- **원칙:** 실제 학교를 선택해도 등장하는 사건·학생·교사는 모두 허구. 가족 형태, 외모, 계약 형태를 희화화하지 않으며 학생의 괴로움을 낙인이나 보상 장치로 사용하지 않는다.
