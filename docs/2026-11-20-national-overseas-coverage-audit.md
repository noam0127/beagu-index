## 복구 완료
- 2023년 종합 백분위 212건, 2024년 290건, 2025년 86건을 기존 검증된 학교별 공개 범위 안에서 복구(총 **588건**).

- 2025년 공개 정적자료와 DB 접근 권한이 달랐던 **78건**의 조회 권한을 정정.
- 공개 백분위 DB **7,549건**과 `data/public-lv0-percentiles-v1.2.json` **7,549건**을 학교 ID·연도·점수별로 대조: **불일치 0건**.

## 남은 검토대상
1. **재외한국학교:** 2024년 17개교 문항별 집계와 2025년 4개교 편집본 기록을 보존. 2025년 4개교의 전국 백분위 산식은 같은 기준으로 검증되지 않아 미산출. 학교명·국가별 검색은 유지.
2. **문항 결과 추가 검증:** 국내 편집본 학교·연도 453건에 대응하는 승인 문항집계가 없어, 점수 공개와 무관하게 별도 원자료 재검토가 필요.
3. **학교 식별 불가 원본 10행:** 2023년 3행, 2024년 7행은 기존 감사와 같이 보류(동명이교·행정구역·변경학교 확인 필요). 이름으로 추정 매칭하지 않음.
4. **2026년:** 본 기록과 별도 승인·공개 유예·개인정보 검토 규칙을 유지. 자동 공개 조건은 이번 변경에서 수정하지 않음.
