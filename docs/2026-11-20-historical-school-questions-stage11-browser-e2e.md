## 1. 검증 범위 — 실제 운영 웹 브라우저

Vercel의 격리된 임시 테스트 환경에서 **Playwright 1.65.1 / Chromium Headless Shell 159**를 설치했다. 운영 사이트의 `search-lv1.html`을 Chromium에서 실제 로딩했으며 다음 사용 흐름을 직접 실행했다.

1. 임시 Lv.1 **참여코드** 입력 → 로그인 버튼 클릭 → 인증된 검색 패널 표시 확인.
2. 실제 운영 학교명 검색창에 학교명을 입력하고, 같은 이름의 타 지역 학교를 **학교 ID로 구분**했다.
3. 해당 검색 결과의 **역대 조사결과**를 클릭하여 상세조회 펼침.
4. 2023·2024·2025 중 지정 연도 탭을 클릭, 전국·지역 비교값의 비동기 응답 및 문항 화면 생성까지 대기.
5. 실제 DOM의 `historical-question-row`와 `historical-benchmark-value.school:not(.is-unavailable)`를 계산해 **우리 학교의 승인 문항 표시 개수**와 기대값을 비교했다.
6. 모바일(390×844) 및 데스크톱(1280×800)에서 전체 문서의 `scrollWidth`와 뷰포트 너비를 비교했다.

검증 결과는 DOM **건수·통과 여부만 기록**했으며, 학교의 원본 응답 보기 묶음이나 임시 로그인 코드를 출력·저장소에 공개하지 않았다.

## 3. 운영 데이터 오염 방지 및 테스트 계정 폐기

- 브라우저 테스트는 소유자가 요청한 운영 검증을 위해 **추측 불가능한 임시 레벨1 참여코드**를 `public.beagu_level_codes`에 발급하고 실제 로그인 절차를 수행했다. 다른 실제 인증코드나 계정은 수정하지 않았다.
- 학교 선택·상세조회는 조회수·관심도 통계를 변경할 수 있으므로, Playwright 브라우저에서 **방문/학교 이용 통계 RPC 호출만 테스트용 응답으로 대체**했다. 마지막 완전한 5학교 시나리오에서 **13회**의 이 테스트용 요청이 실제 통계 서버에 기록되지 않도록 차단되었다. 반면 로그인, 학교 검색, 문항 조회, 전국·지역 비교 API는 실제 운영 네트워크를 사용했다.
- 사용한 임시 코드와 식별 가능한 각 테스트 세션은 개별로 삭제했다. 마지막 SQL 검사에서 임시 코드가 **0개**, 두 상세 시나리오의 정확한 생성 시각 구간 내 테스트 세션이 각각 **0개**임을 확인했다. 기존 사용자의 다른 세션은 임의로 삭제하지 않았다.
- 임시 코드는 소스·문서·GitHub에 적지 않았다.
- 원본 문항 데이터 테이블에는 **새 응답/수정/삭제가 없었다**. 운영 DB 기존 2023~2025 승인 집계는 **7,801 학교·연도**, 저장된 문항별 검증 선택값 **143,628개**로 유지됐다.

## 4. 별도로 남겨둘 문제

1. **소집단 재식별 심사**: 한 응답자만 있는 학교의 다문항 보기 결합 결과가 학교 내부 인물에게 추론될 수 있는지 별도로 검토해야 한다. 브라우저에서 정상 표시된다는 것은 공개의 법적·윤리적 적합성 입증과 다르다.
2. **학교 식별 보류 1건**: 2023년 충남 신리초의 원본에 교육지원청 ID가 없어 아산/홍성 동명이교를 확정할 수 없다.
3. **동률 보류 1건**: 2024년 경남 양산 삼성초의 Q01~Q14 모두 선택지가 1:1로 동률이어서 단독 최다값이 존재하지 않는다.
4. **프론트엔드 배포 상태**: 본 감사에서는 사이트 기능을 수정하지 않았고 새 웹/Edge Function 배포를 요구하지 않았다. GitHub 커밋에 대한 Vercel 빌드 횟수 제한은 본 브라우저 검증의 운영 HTTP 성공 여부와 별개다.
5. 이 실험은 기능·화면 흐름을 점검한 것이며 전 화면에 대한 색 대비, 스크린리더, 여러 기종의 크로스브라우저 QA 전체를 의미하지 않는다.

## 결론

**11차에서는 10차까지 남아 있던 '실제 브라우저 E2E 미확인' 항목을 완료했다.** Chromium 브라우저의 실제 레벨1 참여코드 로그인부터 검색·연도 선택·문항 DOM 표시까지 5개 사례 모두 예상대로 작동했다. 기존 미연결 2건은 검증되지 않은 값을 표시하지 않고 보류 상태를 유지한다.
