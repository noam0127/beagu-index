# 난감한 스쿨밴드 024 — 점수 산식·차트 버전별 최고 기록

2026-11-23 · **IMPLEMENTED / GITHUB ACTIONS·BROWSER CI PENDING**

## 점수 및 판정 산식 (실제 게임 소스와 일치)

- 입력 판정: 판정 시점은 사용자 입력 보정값을 적용하여 계산한다. `PERFECT`는 해당 난이도의 PERFECT 판정 시간 이내, `GOOD`은 GOOD 유효 범위까지, 그 외에는 노트를 치지 않은 것으로 처리한다.
- `PERFECT` 점수: `1000 + 5 × min(콤보, 100)`
- `GOOD` 점수: `600 + 3 × min(콤보, 100)`
- `MISS` 점수: `0`, 콤보 초기화
- 콤보: 유효 노트를 순서에 상관없이 판정하면 1 증가, MISS에서는 0; 최고 콤보는 역대 최대값을 표시.
- 빈 입력: 누를 수 있는 노트가 없는 레인을 눌러도 점수와 콤보·판정 횟수는 변화시키지 않으며 `emptyPresses` 카운터만 증가.
- 연주 중 정확도: `round(100 × hits / judged)`, 아직 판정된 노트가 없으면 '—'.
- 완료 정확도: `round(100 × hits / 차트 전체 노트 수)` (완료 시 전 노트 판정 여부 검사).
- 기록 유효성: `judged = 총 노트`, `perfect + good = hits`, `hits + miss = judged`. 중단 또는 누락, 음수·소수·비현실적으로 높은 점수, 실제 플레이 불가능한 곡 유형은 저장 거부. 완료되지 않은 판정이 있더라도 게임 종료·다시하기는 가능하지만 최고점으로 저장하지 않는다.

## 최고 기록 분리
- 저장소: 사용자의 브라우저 `localStorage`, 원격 서버/개인정보 데이터베이스를 이용하지 않는다.
- 저장 키: `nangam-schoolband-best-v2:{schoolId}:{songId}:{chartVersion}:{instrument}:{difficulty}`.
- 실제 교가는 아직 게임용 차트 미등록이므로 `songId`는 기존 자체 창작 원본 `original-shining-our-school`로 유지.
- 기존 `nangam-band-v08:` 최고 기록과는 분리. 과거 곡/차트별 출처 구분이 모호해 자동 이전하지 않는다. 이전 기록을 삭제하지도 않는다.
- 새 점수가 기존 최고 점수보다 높은 경우에만 기록 업데이트(동점·낮은 점수는 저장소 쓰기 없음).
- 오염된 로컬 값(`NaN`, `Infinity`, `1e3`, `0001`, 음수, 소수, 매우 큰 정수 등)은 무시한다.
- 플레이에 `localStorage` 권한이 필요하지 않다. 저장소 읽기·쓰기·삭제 실패는 게임 진행을 막지 않고 안내만 표시.
- ‘이 조합의 최고 기록 초기화’ 버튼은 현재 조합의 v2 키만 삭제하며 다른 악기·학교·난이도·곡·차트 버전 또는 이전 v08 기록을 건드리지 않는다.
- 내부 QA용 생성 차트는 `generatedTrial.catalog.chartVersion` 키로 분리하여 정식 내장 차트 기록과 섞지 않는다.
