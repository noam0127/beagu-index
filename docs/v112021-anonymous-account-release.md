# v1.12.02.1 익명 계정 — 운영 적용 전 확인
- 가입은 서버 검증된 개인 Lv.2만, 아이디는 영문·숫자·밑줄 4~20자리, 대소문자 미구분.
- 로그인 아이디는 HMAC 조회값으로만 저장; 비밀번호는 기존 600,000회 PBKDF2 검증값과 계정별 무작위 salt 사용. 비밀키는 서버에만 저장. 아이디/비밀번호 원문을 로그, 게시물, 인증서, 브라우저 저장소에 남기지 않음.
- 비밀번호 찾기·재설정·복구 기능 없음. 가입 동의 및 로그인 화면 안내.
- 운영 상태 읽기 전용 조사 시 계정 테이블 미존재. 과거 비밀번호 전용 가입 API와 프런트엔드의 운영 적용 여부를 다시 확인하고, 실제 기존 계정이 발견되면 전환 정책을 확정하기 전 서버 변경 금지.
- 별도 운영 승인 후 기존 계정 테이블/세션 컬럼/RPC 준비 및 접근권한 검증, 서버 비밀키 안전 설정, 새 Edge Function 적용, 프런트엔드 적용 순서 결정. 적용 후 실제 생성/로그인/거부 경로 검증 필요. 현 단계에서는 SQL/서버 배포/운영 DB 변경을 수행하지 않음.
- 기존 계정 다듬기 후보 SHA 6f927d46080c0a4703e13ae1b8218542b69203af 보존.
