# 『나의 OO한 학급일지』 2단계 — 설문 문항과 소설 사건의 연결

작업일: 2026-11-19. 기존 배구지수 검색/비교/설문/게임/레벨 시스템은 변경하지 않는다.

## 구현
- js/class-diary-narrative-v1.js: 연도별 질문 128개를 12개의 문학적 장면 주제로 분류한다. 2026년의 정규 질문 원문, 단일 선택 보기, 복수선택 보기, 표형 행과 열을 각각 정규화한다.
- scripts/test-class-diary-narrative.cjs: 128문항 누락·중복·세부항목 검사, 7일 장면 생성 및 승인 조건 검증.
- supabase/functions/class-diary-story-signals-v1/index.ts: 기존 시스템을 변경하지 않는 독립적 읽기 전용 레벨2 인증 API. 서비스 역할 인증키는 서버 내부에만 있다.
- teacher-class-diary.html: 학교 정보·승인 문항 경향을 받아 일주일 장면 소재를 보여주는 개발용 미리보기.
- .github/workflows/class-diary-world-validation.yml: Node 자동 검사와 무인증 접근 차단 검증.

## 원천 확인
- 공개 문항 목록: 2023년 14개, 2024년 14개, 2025년 50개, 2026년 50개. 총 128문항.
- 2023~2025년 문항 자료는 공개 질문 제목 중심이다. 정확한 당시의 질문 원문 및 보기 모두가 확인된 상태는 아니므로 sourcePrecision=public_label_only로 표기하고 과거 보기를 창작하지 않는다.
- 2026년은 js/2026-questionnaire-options-v1.2.js에 문항 원문과 종류(choice, multi, grid, time), 보기와 각 행이 있다. 자유서술형 Q51은 제외.
- 2023~2025 학교별 원자료를 그대로 노출하지 않는다. 일반 집계 7,350행은 OWNER_AUTHORIZED_CLOSED_CHOICE 상태이고, 2025 보충 최다선택 982행·복수선택 2,676행은 검증 상태만으로 게임 공개 권한을 얻지 않는다.
- 별도 공개 검증된 문항 분포 51행(2023:4, 2024:47). 해당 학교 연도 공개 조건을 함께 충족하는 것은 49행. 고위험 문항 차단까지 반영하면 서사 신호 후보 37행(2023:2, 2024:35).
- 2025와 2026에는 아직 공개 검증된 문항별 신호가 0건이다. 2026년 스냅샷 WITHHELD 자료는 조회하지 않는다.

## API 공개 조건
1. 정확한 운영 초등학교 ID 및 만료 전 레벨2 세션을 서버가 검증.
2. 학교-연도 공개 상태 PUBLISHED, privacy_reviewed=true, 유효한 백분위.
3. 문항 공개 승인 APPROVED_AGGREGATE_ONLY, reviewPolicy=N10_CELL3_PATTERNS5_STRICT_MATCH, valid_response_rows>=10.
4. 민감도가 높은 교권침해·병가, 성별/나이, 아동학대 신고 등 문항은 학교별 사건 신호에서 제외.
5. 2026년은 manual_release_approved=true를 추가 요구.
6. 응답 수·원시 분포·응답자 정보는 브라우저에 전송하지 않음. 승인 조건 충족 여부만 전송.

## 서사와 사실의 구분
학교별 과거 설문 최다선택 응답은 2027년의 현재 모습이나 특정 사람의 실제 행동을 증명하지 않는다. 이야기 장면은 모두 허구이며, 검증 신호가 없는 곳에서는 일반적인 교직 경험만 사용한다. 실제 교직원 대사를 재현하지 않는다.

- 2023~25 원문 문항과 보기 및 2026 세부 행 응답의 추가 공개검수.
