# 2023~2025 학교별 실제 설문 응답 검증과 공개 안내문 변경

적용일: 2026-11-17. 대상: `noam0127/beagu-index` main, Supabase `snvzwrexuqavnfvzgxqj`.

## 1. 화면 안내문 조정
- `index.html`·`challenge.html`: **“1,000명 달성 시 2026 배구지수 자료를 공개합니다.”** 문구 제거
- `js/challenge-progress-v1.js`: 목표 달성 뒤 `자료 공개를 준비합니다` 메시지 제거
- `search.html`, `search-lv1.html`, `school-report.html`, `statistics.html`: **“자료 공개·열람 기준 확인”** 링크 및 해당 메뉴 제거
- 챌린지 진행률 자체와 Lv.1 참여코드 인증은 유지
- `release-policy.html` 원문은 당장 삭제하지 않음: 공개메뉴에서 비노출이나 내부 감사·권한 원칙은 유지. 링크를 숨긴다고 서버 접근을 완화하지 않음

## 2. 원본 비교
- 2023: 소유자 구글시트 `raw_data : 배구지수 시즌1 (2023)`
- 2024: `raw_data : 배구지수 시즌2 (2024)`
- 2025: `raw_data : 배구지수 시즌3 (2025)`
- `public.schools`의 운영 학교명과 시도를 정규화한 **유일한 일치**가 있는 경우만 연결. 같은 지역·이름으로 학교가 둘 이상이면 자동 연결하지 않음
- 실제 질문별 선택지가 있는 2023년 Q01~Q10과 2024년 Q01·Q02·Q04~Q14에 한해 원자료의 1~6점 응답 번호를 원본 선택지로 매칭
- 2024년 Q03 원래 보기 불명, 2025년 원본의 전체 응답 범위 미확인 등은 그대로 제외

## 3. 학교별 공개 심사
단일 설문 제출을 교사 한 명이라고 단정하지도, 10개의 제출을 고유 교사 10명이라고 단정하지도 않는다. 공개 대상은 다음의 **보수적 자동 교차 검증**을 전부 통과한 학교-연도-문항만이다.

- 정확하고 유일한 학교명·시도 매칭
- 해당 학교의 원본 응답 행 10건 이상 + 구분 가능한 제출 시각 10개 이상
- 전체 응답에서 서로 다른 문항 응답 패턴 5개 이상
- 해당 문항 유효 선택 응답 10건 이상, 원본 범위를 벗어나는 응답이 없음
- 두 개 이상의 보기가 실제 선택되고, **선택된 모든 보기별 빈도가 3 이상**
- 문항이 원본 검증된 객관식이며 개인 실명·연락처·주관식이 아님
- 사용자에게는 **보기별 10% 단위로 반올림한 비율과 최다 선택 보기만** 전달. 응답 건수, 개별 응답 원본, 검증용 빈도수는 제공하지 않음
- 선택지 비율을 각각 반올림하므로 백분율 합계는 100%가 아닐 수 있음

이것은 개인정보/재식별 위험을 완전히 소거했다는 보증이 아니다. 원본 시트에 교사별 유일 식별자가 없으므로 동일인 중복 제출 여부를 판정할 수 없는 한계가 있다. 추가로 대상 교사들에게 공개동의를 확인하는 절차가 바람직하다.

## 4. 검증된 공개 범위
- 2023: **3개 학교, 4개 학교-문항 결과**
- 2024: **32개 학교, 47개 학교-문항 결과**
- 2025: 이 원본 범위에서 자동 심사 통과 학교-문항 결과 없음 (무리하게 공개하지 않음)

원본이 불충분하거나 학교 고유 식별이 불확실한 경우 값은 `검수된 학교별 분포 자료 없음`으로 표시한다.

## 5. 시스템 및 권한
- 비공개 저장: `public.beagu_verified_school_question_distributions_v1`; RLS 사용, 익명·일반 인증 사용자에 대한 직접 SELECT 철회, 서버 서비스 역할에만 읽기 허용
- Supabase Edge `beagu-level-api` v18에 세션 확인 후 `schoolDistributions` 응답 추가
- 반환필드: `year`, `questionId`, `modeOption`, `roundedDistribution`만. **검증에 쓰인 원본 응답 행 수는 API에서 제외**
- LV.1 `js/level-search.js`: 연도별 학교 상세에 최다 선택 보기와 반올림된 분포
- `school-report.html`: 동일한 결과 및 기존 전국/시도 비교값, 원래 설문 선택지 모두 표시
- 서버에서 공개 대상을 `APPROVED_AGGREGATE_ONLY`로 필터. 2025년 학교별 미검증 응답은 반환하지 않음

## 6. 확인된 테스트와 한계
- Supabase 배포 ACTIVE, 조회 테이블 RLS·권한 확인
- 학교별 집계자료에 유효 응답 10 미만인 항목 없음, 지정된 QA/승인 상태만 저장된 것을 DB로 검증
- GitHub 코드에서 1,000명 공개 약속과 자료공개 기준 링크 제거 확인
- 실제 `baeguindex.com` 운영 배포, 소유자의 실사용 LV.1 참여코드 로그인 시나리오, 브라우저 E2E 테스트는 별도 확인 필요
