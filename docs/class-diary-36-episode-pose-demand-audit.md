## 목적
**실제 게임에 필요한 이미지**를 선정하고, 생성 이미지를 무작정 8장씩 늘리지 않는다. 현재 엔진은 36화별 컷을 배정하지만, 모든 컷이 서사 분석으로 선정된 것은 아니다.

## 36화 포즈 배정 점검
남성 3명 × 36화 = **108개**. 명시적 `SPECIAL` 배정 14+12+13=**39개**, `DEFAULTS` 순환 배정 **69개**. 따라서 순환 배정을 근거로 "모든 8포즈가 새로운 원화로 필요하다"고 결론 내리면 안 된다.

위 숫자는 **코드상 배정 횟수**이지, 모든 플레이어 루트에서 실제 화면에 표시되는 횟수나 장면의 예술적 필요성을 뜻하지 않는다.

## 제작 우선순위
1. 명시적 39개 회차의 대사와 실제 행동을 먼저 대조한다.
2. 소품 포함: 차도겸 실뜨기, 백태오 배구공, 한현우 책/수첩은 해당 행동이 실제 등장하는 장면일 때만 특별 포즈를 추가한다.
3. 나머지는 승인된 기본 대화·미소·경청 컷으로 재사용한다.
4. 이미지가 부족한 회차에서는 미승인 새 얼굴 대신 **기존 게임 사진 또는 배경만 보이는 기존 연출**을 유지한다.
5. 최종 미술 승인/모바일 시험 전에는 어느 컷도 자동으로 게임에 연결하지 않는다.

## 현재 결론
- 검수 후보 한현우 5컷은 원본을 기반으로 투명화했지만 **기술 후보**일 뿐 사람의 최종 미술 승인을 받지 않음.
- 차도겸·백태오는 원본 8열 시트에서 여러 손/팔이 이미 잘려 새 개별 원화가 필요.
- 신규 얼굴이 기존 얼굴과 달라지는 생성 결과는 승인 금지.
