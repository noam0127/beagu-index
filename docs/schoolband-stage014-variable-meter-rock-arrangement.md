## 1. 구현된 편곡 엔진과 범위

`scripts/schoolband-rock-arranger-v1.cjs` — **`schoolband-rock-arranger-v1.0.0`**

- **일반화된 곡 시계:** 1박 = 480 MIDI PPQ tick, 최소 표준 그리드 120ticks(16분음표). 마디 단위 박자 변경(2/2·3/4·4/4·5/4·6/8 등 분모 2·4·8, 분자 2~9), 16분 그리드상의 곡 중간 BPM 변경(40~220)을 지원. 마디 길이는 `480×4×분자/분모`로 산출하고 마디의 시작·종료 tick을 누적한다. `tickSeconds(t)`는 **템포 구간별 시간을 적분하여** 시작·끝 초를 결정한다. 단일 BPM/단일 박자를 전체 곡에 곱하는 방식은 금지한다.
- **원곡 멜로디 보존:** 입력 선율의 `startTick/durationTicks/pitch/velocity`를 그대로 출력한다. 원곡 멜로디의 `humanizeMs=0`; 기타 반주를 바꾸는 과정에서 원곡의 음높이·시각·길이를 훼손하지 않는다. 같은 음의 종료가 템포 변경 경계를 넘어가더라도 두 템포 구간의 실제 시간을 각각 합산해 `endSeconds`를 계산한다.
- **자동 반주 생성:** 각 마디의 올바른 3화음(장3도/단3도)을 기반으로 드럼(8분 하이햇·박자별 킥/스네어), 베이스(근음·완전5도, 일부 다음 마디 직전 8분음표 픽업), 기타(근음+완전5도 파워코드 및 당김 업스트럼), 키보드(조성별 근음·3도·5도)를 생성한다. **6/8박자의 강세는 3개의 8분음표가 묶인 점4분음표 단위**로 다뤄 4/4의 강세 규칙을 그대로 적용하지 않는다.
- **인간적인 연주 느낌:** 원본 멜로디는 정확한 시간축을 유지하고, 생성 반주에만 지정된 seed 및 곡 ID·악기·tick·pitch를 해시해 **-4~+4ms의 재현 가능한 미세 발음 시차**를 부여한다. 강박/묶음강세/박자/약박으로 구분한 **강세계수 1.0/0.90/0.82/0.69**를 velocity에 적용한다. `Math.random()`를 쓰지 않아 같은 입력·seed는 결과와 SHA-256이 완전히 같다.
- **믹싱 프리셋:** `master=.80`, `melody=.96`, `drums=.44`, `bass=.48`, `guitar=.40`, `keys=.37`, `playerHit=.80`를 출력에 명시한다. 이 값은 **편곡 미리듣기/렌더링용 힌트**이며 기존 실게임의 음향 버스 또는 20개 난이도 차트를 자동 덮어쓰지 않는다. 실제 게임 연결은 015/030의 곡 등록 품질 게이트 이후로 분리한다.
- **화성 감사:** 악기 반주 세 파트(기타/베이스/키보드)의 발생 음이 현재 마디의 근음·올바른 3도·5도에 들어오는지 판별하며 잘못된 #3·불협화음이 발생하면 거부한다. 멜로디의 장식음/경과음은 원래 창작 선율 일부이므로 임의로 변조하거나 반주 화성 충돌로 오판하지 않는다. 코드의 원본/장·단 여부가 없거나 빈 파트/음표 범위 오류도 실패한다.
- **권리 제약:** 코드가 직접 창작한 시범곡 ID 2개만 `demo_original`로 허용한다. 제3자 `approved` 항목은 **변환 목적 권한·증빙 ID·미만료 날짜·공개금지**를 요구하되, 증빙의 *진위 여부*나 실제 이용 허가 계약의 내용 검증은 하지 못한다. 022~023단계의 실제 권리 확인 없이는 실학교 교가를 받거나 공개하지 않는다.

**013단계 MIDI/MusicXML 파서는 여전히 고정 4/4·고정 BPM만 수입한다.** 014단계의 새 편곡 엔진은 **이미 정규화된 JSON 이벤트**로 가변 박자·템포를 지원한다. 원본 MIDI/MusicXML의 실제 템포 맵/박자표 변경을 끝까지 파싱하는 일반화는 아직 구현하지 않았다. 또한 생성 반주를 4악기×5난이도 노트·레인으로 자동 전환하고 실제 곡 게시/학교 선택까지 연결하는 단계는 **015/030**이다.
