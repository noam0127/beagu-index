# 『나의 OO한 학급일지』 3단계 — 학교·문항·사건 연결 매트릭스

작성: 2026-11-21. 브랜치: `feat/class-diary-school-simulation-phase1-20261121`. 운영 반영 전 설계·정적 검증용.

## 산출물
- `data/CLASS_DIARY_EVENT_VARIABLE_MATRIX.json`: 20개 작가 검토 대상 사건 맥락과 60개의 서로 다른 연도-문항 참조, 공식 학교 사실키, 연결 회차(1~36).
- `scripts/test-class-diary-event-variable-matrix.cjs`: 128개 문항의 연도별 고유 ID, 학교 세계 생성기 공식 필드명, 회차 범위, 허구·증거 경계의 정적 검사.
- 출처: `data/BEAGU_2023_2025_VARIABLE_DICTIONARY.json`, `data/BEAGU_2026_VARIABLE_DICTIONARY.json`, `js/class-diary-world-v1.js`.

## 가변 사건의 인과 관계
| 구조 | 예시 | 검증 조건 |
|---|---|---|
| 학교 객관정보 → 장소 | 승인된 `meal_place` → 급식 이동 장면 | 승인된 공개 자료의 기준연도 확인 |
| 공식 시설자료 → 연출 | `teacher_support_spaces` → 동료가 빵을 건네는 장소 | 유무·결측에 따라 장소만 변경 |
| 설문 문항 → 서사 질문 | 2026-Q04 → 회의 발언을 망설이는 선택 | **문항의 존재만으로 해당 학교 분위기를 판정하지 않음** |
| 선택 이력 → 재등장 | 4·9화 줄서기 선택 → 22·32화 안전 규칙 재검토 | 후속 플래그 미구현, 다음 엔진 단계에서 연결 |
| 공식 외부 시계열 → 구조 변화 | 신축 입주·학생 수 증가 → 학급 편성 갈등 | 현행 매트릭스에서는 불허, 외부 확인 이후 추가 |

## 보수적 공개 원칙
1. **현재 모든 사건의 기본 활성화는 허구**이며 학교별 공개·승인 데이터가 연결되기 전까지 특정 학교 조사 결과로 조건부 활성화하지 않는다.
2. 승인 학교정보 숫자·범주를 배경에 쓰더라도 사건의 발생률·학생 행동·교사 태도를 예측하지 않는다.
3. 2023~2026 유사 문항에 같은 사건 태그가 붙어도 문항 간 척도 통합을 의미하지 않는다.
4. 2026년 문항은 공개 승인된 학교별 집계가 확인되기 전까지 메타데이터로만 이용한다.
5. `district_housing_price_mean`은 행정구역 평균이며 학생 가정형편이나 실제 전학생 발생을 뜻하지 않는다.
6. `september_participation_rate`은 과거 공개 집계에 한정한다. 개인 참여·정치적 속성 추론 금지.
7. 학교 증축·통폐합·학급 조정 등은 별도 공식 계획 없이 사실로 그리지 않는다.
8. 이 파일의 20개 행은 **사건 조건·문항 연결 후보**이지 300개 완성 원고의 일부를 완료했다는 뜻이 아니다.
