## 검수에서 발견한 연속성 문제
1. 차도겸의 복선 상징은 기획 문서에서 **파란 실·풀린 매듭**으로 기재되어 있음.
2. 그러나 기존 8포즈 이미지의 실뜨기 소품은 **붉은 실**이고, 기존 원본 사진을 분리한 투명 컷에도 같은 색이 남아 있음.
3. 이를 수정할 때 얼굴과 손의 픽셀을 다시 그리거나 상처 없이 확인하지 않은 색상 변경을 자동 승인하지 않는다.
4. 대안: **원고의 실 색을 붉게 통일할지**, **검수된 게임 소품을 파랗게 수정할지** 작품 전체에 하나의 결정만 적용해야 함.

## 실제 36화 사용 빈도
- 현재 남성 3명 × 36화 = 108개 포즈 배정
- 특정 회차와 포즈를 직접 연동한 `SPECIAL` 39개
- 단순히 8포즈를 순환하는 `DEFAULTS` 69개
- 8종 모두 등장한다고 해서 **8종 모두 새로운 별도 원화가 필요**한 것은 아님.
- 동료 사건 모듈: 도겸 17장면·태오 19장면. 실제 화면 등장/분기 조건을 확정한 뒤 필요한 동작만 제작.

## 게임 적용 전 필수 기준
- 한현우: 『논어』만 읽음. 기안84풍 헝클어진 **헤어스타일**은 참고하되 실제 인물의 얼굴을 재현하지 않음.
- 서지윤: 베이스기타 및 보라색 부분 염색이 해당 회차와 설정에 모순되지 않음.
- 차도겸: 실뜨기 줄 색, 아이에게 참여를 강요하지 않는 동작, 손가락 및 실의 전경 마스크 보존.
- 백태오: 배구공의 자연스러운 크기와 손의 접촉, 실제로 배구에 참여하는 장면만 특별 포즈 활용.
- 원본 얼굴 불일치·잘린 팔·마스크 누락이 있으면 신규 PNG를 자동 배포하지 않고 원본을 유지.
