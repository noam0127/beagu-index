# 2026-11-20 배구지수 학교별 문항 5차 원본 일치 감사

## 이번 단계의 변경
- 운영 Supabase `public.beagu_school_question_aggregates_v2`에 2024년 **12개교 / 153개 검증 문항**, 2025년 **18개교 / 786개 검증 문항** 신규 집계 추가, 합계 **30개 학교·연도 / 939개 문항**.
- 2025년 복수선택형 보충 결과를 `public.beagu_school_question_modes_supplement_v1`에 **12개 추가**: Q04 1개, Q30 11개. 미검증·동률 제외.
- 원본 확인은 해당 연도 사용자 구글 시트와 `public.schools`를 대조. **시도 + 교육지원청 + 학교명**을 기본 필수값으로 사용하고, `수원신성초`처럼 학교명 앞에 교육지원청 지역명이 붙은 경우만 명시적 접두사 제거로 정규화.
- 제주 지역에는 학교 공식 교육지원청이 `제주시`/`서귀포시`로 표기되나 원본에는 `제주`/`서귀포`인 경우가 있어 해당 두 명칭만 따로 동치 처리.
- 정규화된 원본 학교명이 동일 시도에 별도의 독립적인 공식 학교명으로 존재하는지 조회: 충돌 0건. 한 원본 행을 둘 이상의 학교에 동시에 연결하지 않음.
- 2024년 보충자료의 응답 행 13개(그중 11개교 한 행), 2025년 응답 행 20개(16개교 한 행)는 DB 내부에서만 참조하며 외부 API에 건수를 반환하지 않음.
- `anon`·`authenticated` 두 역할 모두 내부 집계 및 보충 테이블의 직접 SELECT 권한 없음. RLS 활성화. 2026 데이터는 수정하지 않음.

## 원인과 중단 이유
- 조사 편집본에 존재하지만 검증 완료된 문항집계가 없는 학교·연도는 **32건**. 개별 원본 응답 부재를 증명하는 수치가 아님.
- 2023년 충남 신리초등학교: 공식 학교가 아산과 홍성 두 곳에 있고, 원본의 `충남 신리초등학교` 응답 세 행에는 교육지원청이 없어 학교 ID를 확정할 수 없음. 해당 학교에 임의 배정 금지.
- 2024~2025년 나머지는 확실한 학교명·교육지원청 일치가 없는 대상이다. 레벤슈타인 거리로 가까운 이름이 있다고 해도 동일 학교라는 증거가 아니므로 **유사도 자동 연결 금지**.
- 다음 단계는 변경·폐교·병설·분교 이력과 학교명 별칭을 공식 문서로 검증하거나, 이미 소유한 원자료에서 승인된 학교 식별 키를 찾아야 한다. 근거가 확보되기 전에는 더 이상 공개 문항을 생성하지 않는다.
- N=1 집계의 최다 선택지 공개에는 재식별 가능성이 남으며 운영자 공개 의사가 개별 응답자 동의나 법적 검토를 대체하지 못한다.
