# 난감한 스쿨밴드 — 2곡 선택 구조 (2026-11-23)

## 확정 UX 계약
학교 검색 → 곡 선택 → 악기 선택 → 연주. 기존 3개 주요 패널을 유지하며 곡 선택은 악기 패널에 배치.

- 배구 테마 연습곡: 항상 플레이. 현 단계에서는 기존 직접 창작 멜로디를 임시 재사용하며 새로운 배구 노래를 작곡한 것은 아님.
- 학교 교가: 현재 게임용으로 승인된 교가 0곡. 빈 카탈로그를 기본값으로 사용해 버튼 잠금. 확인된 학교 ID·권리·차트·등록 승인 없이는 활성화하지 않음.
- 학교별 공개 배구지수 난이도와 교가의 등록/권리 상태는 서로 다름.
- 학교 검색 실패: 9초 요청 제한, 재시도 버튼, 가상 학교/배구 테마 연습곡으로 우회.
- 최고 기록: 학교 ID·선택곡·악기·난이도별로 별도 저장. 이전 기록키 자동 이관 없음.

## 30단계 변경
- 020: 2곡 선택, 미등록 교가 잠금, 학교조회 장애 복구.
- 021: 공식 학교 사이트/영상에서 교가 메타데이터 탐색. 무단 다운로드 및 추출 금지.
- 022–023: 권리 승인, 검수된 교가 MIDI/차트, 철회 및 실제 음악 재생 연결.
- 024: 곡 ID와 차트 버전까지 포함한 최고기록 분리.
- 026–030: 등록/미등록/장애 시나리오 및 실제 음향·모바일·배포 전수 검사.

## 7개 AI 전문가 역할 검토
1. 리듬게임: 기존 판정 엔진을 유지하고 곡 선택만 분리.
2. 음향: 기존 직접 창작곡 재사용을 표시하고 새로운 배구 신곡이라고 주장하지 않음.
3. 연출: 2개 선택 버튼과 비활성 사유를 명확히 표시.
4. 데이터: 학교 ID·공개 지수 난이도·교가 등록 여부를 분리.
5. 접근성: 선택 상태 및 disabled 처리, 상태 메시지.
6. 보안/저작권: 확인된 게임 권한과 차트가 없으면 교가 선택 잠금.
7. QA: 회귀 테스트와 신규 브라우저 케이스, GitHub 시험 브랜치 격리.
