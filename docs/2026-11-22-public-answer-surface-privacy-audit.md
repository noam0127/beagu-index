## 실제 확인한 서버 상태
- `public.beagu_2026_results_snapshot`, `public.beagu_2026_qa_ingest_staging`,
  `public.beagu_metric_catalog`, `public.beagu_release_metrics_v2`은 RLS가 켜져
  있으며 **anon/authenticated의 직접 SELECT 권한이 없음**을 운영 DB에서 확인.
- 관련 학교별 결과 공개 RPC(`beagu_2026_released_question_results`,
  `beagu_2026_lv2_released_question_results`)도 anon/authenticated EXECUTE 권한이 없음.
  서명된 `beagu-level-api` 내에서 service role로만 호출.
- 공개 RPC는 원본 해시 일치, APPROVED, 근거 VERIFIED, 관리자 감사 기록,
  24시간 지연(Lv1) 등의 조건을 검증하고 Q31·Q51을 제외.
- 운영 2026 비공개 집계 **394개교**, 공개 승인 **0개교**, 검증된 공개 근거 **0개교**.
  따라서 이번 검증에서 실제 2026년 학교별 조사 답변의 공개 전송을 허가하지 않음.
- 브라우저의 `schoolQuestionResults2026`는 승인된 보기 표시값만 받고
  개별 원본·응답 건수·보기별 빈도수는 전달받지 않음.

## 발견한 위험과 조치
1. **검색 페이지**: 60초마다 공개 승인을 재조회하지만 실패 시 기존 2026년
   문항 표시를 남겨둘 수 있었음. 이제 서명 API 재검증 실패 시 2026년 민감 표시만
   제거하고 오류/재확인 버튼을 제시. 탭 전환 후 옛 클로저 값 재표시도 방지.
2. **학교비교**: 서버 조회 실패 시 보관하던 2026년 승인 문항과 공개 백분위가
   유지될 여지가 있었음. 이제 실패 시 해당 연도 캐시만 무효화하고 과거 연도 유지.
3. **학교 상세**: 보호 집계 또는 공개 백분위의 새 조회 실패 시 직전 2026년
   표시를 유지할 수 있었음. 실패 시 해당 연도 데이터만 숨기고 재조회 안내.
4. **과잉 안내문 방지**: 일반 공개 페이지에 응답 1건·표본수·내부고발 관련
   별도 안내를 추가하지 않음. 설문 설명도 수정하지 않음.
5. **단일 응답의 의미론적 위험**: 표본수가 API에 없더라도 학교별 최빈 선택값은
   실제 1건인 경우 해당 응답과 같을 수 있음. **이것은 기술적으로 익명화되었다는
   보증이 아니며**, 기존 소표본·재식별·동의 범위 검증을 유지해야 함.
