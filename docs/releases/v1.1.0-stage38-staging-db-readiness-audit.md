## 관리자 승인 이전 완료 기준

1. v1.1.0의 Lv.3 회원가입/로그인, Lv.2 추천 승급, 포스트잇, 관리자 회원관리 등 실제 E2E 사용 경로를 목록화하고 각각 필요한 시험 전용 테이블·RPC·RLS·Edge Function을 확정한다.
2. 필요한 구조는 승인된 시험 전용 마이그레이션으로 구성한다. **실사용자 개인정보, 2026 설문 원본, 전화번호, 방문기록, 추천 고유코드 등 운영 데이터를 시험 DB에 복사하지 않는다.**
3. 정상/권한없음/실패 응답을 모두 별도의 시험 계정과 가짜 데이터로 검증한다. 이 문서는 데이터 쓰기를 수행하지 않았다.
4. 위 SECURITY DEFINER RPC의 권한 및 경계조건을 확인한다. 검토 없이 RLS를 끄거나 무조건 GRANT를 추가하지 않는다.
5. 보호된 GitHub Environment, 소유자 승인, 최신 RC manifest SHA-256 검증이 완료된 다음 독립 Vercel **preview**에만 배포한다. 기존 운영 주소와 별도 시험 사이트 대표 URL은 교체하지 않는다.
6. 보호된 승인 URL의 실응답·전체 파일 무결성·브라우저 스토리지 분리·인증·RLS E2E까지 완료한 이후에만 38단계 종료를 검토한다.
