# 배구지수 v1.1.0 — 22단계: Lv3 전용 2026 학교 기본정보·정렬의 출처 검증

**작성: 2026-11-22. 개발 브랜치의 보안 DB 마이그레이션·전용 Edge 읽기 API·Lv1/Lv2 정렬 권한 정리·격리 CI 검증 완료. 실제 Supabase/NEIS 동기화 데이터·인증 사용자·시험/운영 웹 미변경.**

## 기준연도와 공개 원칙

- **Lv0/Lv1/Lv2**: 기존 검색/학교 기본정보 응답을 유지. 기존 2024~2025년 승인 공식 수치·비율 및 2025년 공시가격을 2026 자료라고 바꾸지 않음. 단, 학교명·주소와 같은 기존 학교명부는 별도의 NEIS 동기화 결과이므로 **모든 필드가 역사적으로 2025년 스냅샷으로 동결됐다고 주장하지 않는다**.
- **Lv1**: 공시지가 정렬은 잠금. 서버 `beagu-level-api`가 실제 현재 참여코드 세션 레벨을 확인하고 Lv1 요청은 `403 LV2_REQUIRED_FOR_HOUSING_SORT` 거부. `js/level-search.js`도 Lv1 공시지가 선택지를 비활성화하고 실제 Lv2 서버 판정 시 활성화. 기존 2025년 승인 자료 자체를 수정하지 않음.
- **Lv2**: 기존 학교명·주소·학생 수·배구지수·조회수·2정교사 비율·남교사 비율·공시지가 등의 정렬 기준을 유지. **2026 미승인 신규 학교 기본정보는 전용 Lv2 API에서 반환하지 않는다**.
- **Lv3**: **실제 Supabase Auth+현재 Lv2 추천 품질+18단계 원기기·계정 독점 연결+19단계 활성 Lv3 30분 토큰 및 릴리스 ON**을 서버에서 재검증한 경우에만 별도의 **검토된 2026년 학교 기본정보** 조회 가능. 등록된 검증 원본이 없으면 최신정보가 없음을 표시한다. Lv3 가입만으로 학교 자료 공개 불가.

## 구현

### 1. 엄격한 2026 원본·심사 원장

`supabase/migrations/20261122004000_beagu_lv3_2026_official_school_facts_v1.sql`:

- **새 개인/학교 원본 데이터는 전혀 넣지 않는** `beagu_private.lv3_official_school_facts_2026_v1` 테이블. 학교코드는 7자리 영숫자 학교 ID로 `public.schools`와 연결하고 기준연도는 **2026년 고정**.
- **NEIS 학교 기본정보**: 2026년 원본 식별자·SHA-256 검증값·기준일·학교명·주소·교육지원청·설립 형태를 따로 기록. `neis_reviewed`가 참이고 관리자 승인·학교 식별·개인정보·재식별·이전 자료 결합 위험 검토를 통과해야 공개.
- **학교알리미 등 공식 2026 학생 수/교사 비율**: 별도 `school_info_source_ref/digest/as_of/reviewed`가 모두 유효한 값만 공개. 승인되지 않은 값은 DB에 들어 있더라도 **`NULL`**로 돌려준다. 학생 수·비율을 과거 값으로 자동 보정하지 않는다.
- **2026 행정구역 공시가격**: `housing_source_ref/digest/as_of/reviewed`로 별도 원본을 검증한 경우에만 공개. 과거 2025년 부동산 지표를 2026 자료에 잘못 대입하지 않는다. 세종 등 원자료 미확보 지역에 임의 추정치 사용 금지.
- 소유자 심사는 `review_status='APPROVED'`, 실제 활성 Owner, 검토 시각, NEIS 출처·시점이 모두 유효해야 한다. **출처·수치·학교 위치 등이 변경될 때마다 DB UPDATE 트리거가 기존 승인을 자동 `PENDING`으로 되돌린다**. 비활성 Owner·자료 기준일 미래·미확인 출처는 즉시 열람 불가.
- 비공개 원장에 RLS 적용. `anon/authenticated` 직접 조회/수정 불가, `service_role`은 원장 **읽기 전용**. `public.beagu_lv3_2026_school_facts_v1`은 `security_invoker=true`인 좁은 투영으로, 일반 클라이언트 SELECT 금지. 전역 Lv3 기능 스위치 **기본 OFF**이고 해당 뷰에서도 재확인한다.
- 기존 2025 백분위 `beagu_percentile_2025`와 공개 승인 조회 수 `view_count`는 기존 제한된 원본 뷰에서 가져오되 **2025 백분위의 기준연도를 필드명으로 명확히 구별**. 2026 학생 수/공시가격/비율은 신규 승인 원장 값만 사용한다.

### 2. Lv3 전용 조회 및 지역 정렬 Edge API

`supabase/functions/beagu-lv3-school-facts-v1/index.ts`:

- `school`(검증된 학교 1곳의 2026 기본정보), `ranked`(지역/교육지원청/학교명 검색과 승인 데이터의 가나다·주소·학생 수·교사 비율·공시가격·2025 배구지수·조회수 정렬) 두 POST 동작.
- **세 가지 증명을 함께 서버 검증**: 2026 Lv2 세션/실제 유효 추천, 이메일 인증된 Supabase Auth 사용자와 살아 있는 세션, 원기기 계정 연결·릴리스 스위치·토큰 만료를 포함한 19단계 `beagu_lv3_verify_session_v1` 임시 토큰. 요청 본문의 `level=3`, 브라우저 Lv3 배지, 임의 school ID만으로 승인 불가.
- 반환할 열을 명시적으로 지정해 학교 식별·검증된 수치와 각 기준일만 반환. 원본 출처 URL/해시, 개인정보·응답자 수, 심사자 UUID, 고유번호 원문·JWT를 공개하지 않는다. 조회는 최대 20개/페이지, 검색과 정렬은 고정된 필드 허용목록이며 `no-store`.
- **승인 자료가 없으면 `not_verified`**. 데이터가 있어도 특정 2026 공식 지표 출처를 확인하지 못했다면 값 `NULL`. '숫자 0'이나 오래된 2025년 정보를 2026년 최신값으로 위장하지 않는다.
- **실서비스 배포 및 검색화면 연결 미실행**. 기존 검색·학교 상세 HTML과 운영 데이터베이스는 건드리지 않음. 차후 전체 화면 통합 시 검증된 Lv3 사용자에 한해 이 전용 API를 사용하도록 연결·E2E 테스트가 필요.
