# 배구지수 v1.1.0 — 200단계 초세분화 순차 개발 진행 기록

- 기준: 2026-11-21 (Asia/Seoul)
- 관리 브랜치: `develop/v1.1.0-restart-20261121`
- 버전: `v1.1.0`; 시험 후보: `v1.1.0-rc.1` (미생성)
- 원본 42단계 진행 기록: [`v1.1.0-progress.md`](./v1.1.0-progress.md). 기존 기록 및 커밋 보존.
- **최종 목적**: Lv2 성취 보유자의 이메일 인증·로그인 후 Lv3 자동 승급, Lv0~Lv3 혜택·2026 공개 정책, 전화번호 선택 동의, 회원관리, 참여코드 A-04, 추천·설문 보호, 챌린지·학교정보 개선 및 관리자 승인형 배포.
- **게임 관련 개발 전부 제외**. Lv1·Lv2 기존 기능, 2023~2025 공개정책, 기존 인증 및 추천 기능 보존.
- **A-04**: 2026 설문 참여가 확인된 비활성 고유번호는 Lv1, 유효한 추천 1건 이상 확인되면 동일 코드로 Lv2. 서버 권한 판별, 코드 값 불변.
- **실행 규칙**: 사용자 `ㄱ` 1회 = 현재 미완료 최상위 순번 1개만 실행. 실패/권한/미검증 시 완료라고 하지 않음. 매번 소스·테스트·커밋 SHA·차단 사유 기록.
- **보안 규칙**: 운영·시험 DB/Auth 분리, RLS 비활성화 금지, 운영 코드·DB 임의 변경 금지, 관리자 명시적 승인 전 운영 배포 금지.
- **현재 진행**: 001~005 완료 / 다음 **006** / 총 200단계 중 5단계 확인 완료. 기존 42단계에서 완료한 점검·검사는 증거로 재사용하며 중복 배포 금지.
