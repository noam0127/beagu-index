# 배구지수 v1.1.0 — 21단계: 2026년 자료 공개 시간차와 서버 심사 연결

**작성: 2026-11-22 / 상태: 개발 브랜치 코드·독립 PostgreSQL 16·Deno/Node/CI 검증 완료. 운영·시험 Supabase DB·Edge·Google Forms·실제 Auth 회원 및 웹 배포 미변경.**

## 운영 정책

공개 지연의 시작점은 **2026 자료의 해당 학교·정확한 스냅샷에 대한 관리자 승인 시각 `approved_at`**이다. 모든 등급에서 승인된 최신 자료만 대상이며, 업데이트 시 이전 승인으로 공개할 수 없다.

| 확인된 서버 자격 | 2026 승인 자료 열람 시작 |
|---|---|
| Lv0 | 기존 공개 자료만. 신규 서버의 2026 개별 문항 공개 권한 없음 |
| Lv1 | **독립 심사 승인·최종 변경 후 24시간** |
| Lv2 | **독립 심사 승인·최종 변경 후 6시간** |
| Lv3 | **독립 심사 승인 후 즉시(0시간)**, 서버에서 현재 회원·토큰 권한 재검증 |

‘즉시’는 **2026 설문이 제출되자마자** 공개한다는 뜻이 아니다. 정확한 원본 스냅샷의 학교 매칭, 응답 품질, 개인정보/재식별, 공개 법적 근거 및 학교별 관리자 승인이 끝나야 한다. 승인 미완료/반려/소표본·재식별 우려 상태는 **시간에 관계없이 전 등급 공개 불가**.

## 서버 구현

### 1. 2026 문항 자료 단일 공개 판정 RPC

`supabase/migrations/20261122003000_beagu_2026_tiered_review_release_v1.sql`

- `beagu_2026_tiered_released_question_results_v1(school_id,level)`는 서버 서비스 역할에서만 호출. 지정된 학교의 **2026년 승인된 정확한 스냅샷**과 관리자 승인자·시각·필수 심사 증빙을 확인.
- `beagu_private.beagu_2026_publication_basis_review`의 `VERIFIED` 상태, 정확한 SHA-256 스냅샷 해시 일치, 공식 고지 출처·법적 근거, 학교별 개인정보·소표본·재식별·이전 자료 결합 위험 검토를 **매 요청 현재 시점**에 확인.
- 등급별 `24 hours`/`6 hours`/`0 hours` 타이머를 `approved_at`에 적용하고 `approved_at >= updated_at`도 확인. 심사 승인 취소, 해시 변경, 검토 보류, 변경 시각 갱신, 문제 응답 검증 실패 시 결과는 `null`(공개되지 않음).
- 원본 자유서술이나 응답자 식별 정보는 반환하지 않음. 2026 민감 문항 **Q31·Q51 제외**. 1인 응답 학교라도 공개 적격성 별도 검토가 없으면 불가.
- 비공개 SQL 및 RPC는 브라우저의 `anon`/`authenticated` 직접 실행을 막고 `service_role`만 접근할 수 있도록 설계.
- 기존 `beagu_2026_lv2_released_question_results(text)`를 **동일한 6시간 검증 RPC에 연결**. 과거에 존재하던 'Lv2 독립 심사 승인 직후 열람' 우회 경로가 운영 반영 시 남지 않도록 함.

### 2. 계정·참여코드 이중 인증을 요구하는 전용 2026 Edge API

`supabase/functions/beagu-2026-tiered-results-v1/index.ts`:

- 2026 고유번호 기반으로 발급한 **실제 유효한 Lv1/Lv2 세션**을 서비스 DB 해시로 검증, 17단계 `beagu_2026_verified_visitor_level_v1`에서 현재 원본 본인 응답·추천 인정 상태를 재확인. UI가 제시한 등급은 무시.
- Lv3 자료는 별도의 **서명·만료 확인된 Supabase Auth JWT, 실제 활성 Auth 세션, 19단계 서버가 발급한 Lv3 임시 토큰**까지 확인한 경우에만 심사 승인 직후 열람 가능. 보유 코드/레벨 표시/신규 가입 사실만으로 Lv3 자료 접근 불가.
- 새 `read_school` 요청은 **학교 1곳만**, 고정된 요청 필드만 허용하고 `Cache-Control: private,no-store` 및 제한된 CORS를 사용.
- DB 내부 JSON의 응답 수·개별 보기 수치·응답자 정보를 브라우저로 넘기지 않음. `publicQuestionResults`를 통해 사전 등록된 **폐쇄형 문항의 공개 가능한 보기 결과만** 응답.
- 공개 심사 실패·미승인·시간 미경과는 모두 동일한 **`not_published` 상태**로 표시해 비공개 사유·소표본 정보를 추론할 수 없게 함.
- 이 API는 **개발 브랜치에만 존재하며 배포되지 않음**. 기존 2026 학교 화면과 실제 트래픽을 이 새 경로로 전환하지 않음.

### 3. 기존 Lv2 2026 수치·백분위 공개 경로 방어

`supabase/functions/_shared/release-policy.mjs`:

- 2026 Lv1은 그대로 승인 **24시간** 조건.
- `releaseMetrics(...,level=2,approvedSnapshot=true)`인 경우에도 `approved_at` **최소 6시간 경과**가 필요. 부주의하게 승인 플래그를 `true`로 넘겨도 승인 직후 자료가 열리지 않음.
- 기존 `beagu-level-api`의 학교 상세·백분위 조회는 6시간이 지난 실제 독립 심사 스냅샷 확인 RPC와 이 JS 최소 대기 조건을 **둘 다 통과해야 함**.
- **2023~2025 기존 공개 정책, Lv0 학교 검색 RLS, 포스트잇·회원가입·관리자 계정 인증은 수정하지 않음**.
- 문화유형·다른 파생 자료처럼 이미 Lv1/Lv2 모두 24시간 이상 보수적으로 제한하는 기존 API는 이번 단계에서 조기 공개하도록 확장하지 않음. 모든 2026 세부 자료의 완전 통합 전환·실서비스 E2E는 후속 검증 대상.
