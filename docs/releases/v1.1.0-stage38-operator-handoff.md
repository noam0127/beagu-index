## 38단계 후속 검토 — 동일 출처 브라우저 보안 차단 (2026-11-22 KST)

- 실제 RC `js/supabase-config.js`는 운영 Supabase URL/공개키를 담고 있다. PR #244의 패키저가 공개 시험 스냅샷의 주소·공개키를 시험 프로젝트로 재작성해야 한다.
- **중요:** `https://baeguindex.com/`과 `https://baeguindex.com/_preview/`는 브라우저에서 **같은 출처(origin)**다. JavaScript의 `localStorage`는 경로별로 분리되지 않으며, 같은 탭에서 `sessionStorage`도 경로별로 분리되지 않는다. 실제 RC에서는 `beagu-visitor-v1`, `beagu-referral-device-secret-v1`, `beagu-level-session-v1` 키의 사용을 확인했다. 단순 Supabase URL 치환을 실제 인증/기기 고유키의 완전한 격리로 주장하지 않는다.
