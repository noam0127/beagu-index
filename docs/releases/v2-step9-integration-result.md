## 검증 한계

이 통합은 수정 경로가 겹치지 않는 **선택된 PR 스택**을 최신 main에 결합한 작업이다.
개별 PR이 정상적으로 통과했다는 사실만으로 최종 통합 버전의 E2E,
Supabase 인증/RLS, DB 마이그레이션, 배포/롤백 기능의 동작을 주장하지 않는다.
다른 채팅방의 모든 개발 결과를 합친 상태도 아니다.

특히 PR #198/#199/#195에 관련된 운영 배포 안전 잠금, 시험 DB 격리,
처음 시험 배포에서 `from_sha=null`인 롤백 문제는 **10~11단계에서 결합 및 검증 대상**이다.
9단계에서는 운영 환경의 배포·DB 변경을 수행하지 않았다.
