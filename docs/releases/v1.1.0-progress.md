## 2단계 조사 기록
- 릴리스 워크플로 `.github/workflows/beagu-release-controller.yml` 확인: 승인된 배포 작업이 있을 때만 `_preview` 아티팩트를 게시하도록 설계됨.
- `scripts/release-manager/worker.py`: `staging_sha`가 없으면 `_preview` 생성하지 않음. 운영 SHA를 기반으로 Pages 아티팩트를 재게시하는 구조.
- 현재 외부 접근 검사에서 `https://baeguindex.com/_preview/` 접근 불가. 검사 환경 DNS 제한으로 HTTP 상태를 확인하지 못함.
- GitHub 커밋 연계 PR 실행 조회로는 예약/푸시 배포 성공 여부를 판정할 수 없음.
- 단계 상태: 차단. 승인된 staging_sha/배포 작업 상태 및 실제 Pages 배포 결과를 확인해야 함. 운영 웹 임의 배포 금지.
