# Lv.1 지역·교육지원청 검색/내림차순 정렬 및 2023–2025 문항 비교 (2026-11-17)

## 학교 검색·정렬
- 화면: `search-lv1.html`, `js/level-search.js`
- 검색: 학교명, 시도별, 해당 시도의 **실제 DB 관할 교육청·교육지원청 드롭다운** (표준 `schools.support_office`의 정확한 명칭 사용)
- 정렬: **학교명순 ↓ / 2025 배구지수 백분위순 ↓ / 승인된 학생수순 ↓ / 행정구역 공동주택 평균 공시가격순 ↓**
- 모든 정렬은 Supabase 서버 조회 `beagu-level-api`의 `ranked_schools`에서 **필터→정렬→20개씩 페이지 이동** 순으로 수행. 화면 20개만 클라이언트에서 재정렬하지 않음
- 없는 지표는 후순위(NULL LAST), 동률은 학교명·학교 ID 내림차순
- 배구지수: 2025년 공개 승인 백분위(2023/2024와 계산 기준이 달라 섞지 않음)
- 학생 수: 검증·승인된 최근 학교별 자료(2025 자료 우선, 없으면 2024)
- 공시가격: 2025 원본의 **행정구역 공동주택 평균 공시가격**, 토지 개별공시지가와 구분
- 학교 기본정보와 시설 지표의 기존 공개 승인 방식 유지

## 연도별 실제 설문과 지리 비교
- 근거: 사용자 소유 `raw_data : 배구지수 시즌1 (2023)`, `시즌2 (2024)`, `시즌3 (2025)`의 실제 응답값 및 기존 검증된 연도별 설문 보기 목록
- `public.beagu_survey_geography_comparisons_v1`: **서버 전용**, 학교명·개인응답·응답자 수·선택지별 빈도 원자료를 노출하지 않음
- `beagu-level-api`의 `survey_comparisons` 액션은 Lv.1 코드 세션을 검증한 뒤 해당 연도의 전국·시도 비교 결과만 반환
- 2023: 검증된 10문항의 순서형 평균과 최빈 보기
- 2024: 검증된 13문항의 순서형 평균과 최빈 보기
- 2025: 확인된 원본의 문항별 최빈 보기; 정렬 가능한 순서형 척도에 한해 평균 선택 번호에 가장 가까운 보기
- 2025 원본은 전체 모집단이 아닌 **현재 확인된 원본 파일 범위**이므로 전국·지역 모두 '참고값', 대표값이라고 단정하지 않음
- 전국·지역의 유효 자료와 최빈 선택지가 미달한 집계는 표시하지 않음. 내부 임계값은 개인정보/소표본 보호에만 사용하며 사용자 화면에는 응답 건수를 공개하지 않음
- 2023~2025에는 확인된 지역·전국 통계를 표시하되, **학교별 개인 응답이나 검수되지 않은 학교별 최빈값을 만들거나 공개하지 않음**
- 학교별 문항 응답은 원본별 학교 매칭, 개별 공개동의와 소표본·역추적 검수를 마친 **별도 승인 집계**가 생겼을 때만 표시 가능
- 2026 Q51과 보호대상 개인 자유서술·식별정보는 비공개

## 문항/보기 복구 범위
- 2023: 전체 문항 목록(14) 중 원전으로 선택지를 검증한 10문항. 나머지 Q11~Q14는 원문 보기를 찾기 전까지 미확인
- 2024: 전체 문항 목록(14) 중 원전으로 선택지를 검증한 13문항. Q03은 실제 원문 선택지 검증 대기
- 2025: 31~50번의 원전 보고서 기반 사실선택 20문항 및 01~30번의 실제 2025 원본 **응답에서 관찰된 보기 30개 문항**. 후자는 원래 폼에 있었지만 한 번도 선택되지 않은 보기가 누락됐을 수 있음. 복수선택은 괄호 안 쉼표를 분리하지 않도록 파싱
- 2026: 기존대로 01~50번 질문·보기 및 그리드 행·열 정보, Q51 비공개
- 복구 파일: `js/historical-questionnaire-choices.js`, `js/2025-observed-choices.js`, `js/2026-questionnaire-options-v1.2.js`
- 상세 UI: `school-report.html`

## 검증 및 배포 경계
- Supabase Edge Function `beagu-level-api` v16: ACTIVE, 기존 로그인·세션·개별 학교 승인 경로 유지
- DB의 2025 공개 백분위·학교별 공식 정보·비공개 공개정책은 변경하지 않음
- 정렬·교육청·전국시도 비교 조회 테이블/뷰는 `anon`·`authenticated` 직접 SELECT 금지, Edge Function 서비스 역할에만 권한 부여
- GitHub `main`에 프런트엔드·백엔드 소스 코드 반영
- 실제 브라우저에서 `baeguindex.com` 최신 코드 반영 및 사용자의 Lv.1 코드 로그인 E2E 검증은 환경/접근 제약상 별도 확인 필요

## 지역 검색 UI 보완 및 자료 검증 — 2026-11-17
- 학교명 정렬은 **가나다순(오름차순)**, 주소 정렬은 **주소 오름차순**을 추가. 그 외 2025 배구지수 백분위/학생 수/공동주택 평균 공시가격은 내림차순, 미확인 값은 뒤에 배치한다. 모두 서버에서 필터→정렬→페이지로 조회한다.
- 교육지원청은 **화면의 이름만 축약**한다(예: `강원특별자치도강릉교육지원청` → `강릉`, `전남광주통합특별시광주동부교육지원청` → `동부`). 필터 값은 원본 `support_office` 문자열 그대로 보낸다.
- 전남/광주 공개 백분위 자료의 부재 확인: 학교 원본 목록에는 전남 457개교·광주 158개교가 있으나 `beagu_school_report_yearly`의 **해당 지역 공개 승인 연도별 백분위는 0건**. `beagu_level_data`의 과거 요약에 `release_status=approved` 항목이 있어도 학교별 응답자 및 공개 재식별 심사 근거를 확인하지 않은 값을 자동 공개할 수 없다. 개인정보 검수 없이 데이터에 `PUBLISHED`를 추가하지 않는다.
- 세종 55개교의 학교별 `housing_price_won`은 모두 비어 있다. 2025년 원본 `2025 배구지수 편집본`의 `최종출력데이터` Q열(행정구역 공동주택 공시가격 평균)에서 확인한 세종 학교 행(1920~1932)도 공란이다. **공동주택 가격 중앙값이나 2026년 평균을 2025년 원본의 행정구역 평균으로 대신하지 않는다.** 출처와 지역별 산정 기준이 일치하는 검증값이 확보될 때까지 미공개 상태를 유지한다.
- 원본 자료 조회 및 공개 심사 여부 검증만 수행하였다. 학교별 신규 승인 값이나 가격을 임의로 작성/배포하지 않는다.
