# 『나의 OO한 학급일지』 — 한국 청춘·연애소설 문체 개정

2026-11-20 · 실제 운영 파일에서 한 문장씩 수정한 창작 원고를 기준으로 정리.

## 문체 기준

- 대사는 **학교에서 실제로 들릴 법한 구어**로. “~해요?”, “끝나고 같이 봐요.”처럼 짧고 상대의 응답을 기다리는 말투를 쓴다.
- 설명보다는 **장면**을 쓴다. “책임은 나누어야 했다” 대신 의자를 끌어와 함께 서류를 확인하는 모습을 보여 준다.
- 감정에는 **여백**을 둔다. “호감이 높아졌다” 대신 메시지를 보내고 휴대전화를 다시 꺼내 보는 순간을 남긴다.
- 교직 사건은 인과관계를 유지하되, 하나의 선택을 도덕적 정답으로 단정하지 않는다. 도움 요청, 수업 준비, 학생자치, 휴식이 서로 다른 결말을 만들 수 있다.
- 교사는 학생에게 신뢰할 만한 성인이다. 로맨스는 **성인 동료 사이에만** 가능하다. 동료의 거절·휴식·선택권을 존중한다.
- 한국 초등학교 용어(주안, 나이스, K-에듀파인, 학년연구실, 학급회의, 전담시간 등)를 대화에서 자연스럽게 사용하고 설명식 낱말 나열을 피한다.
- 개인 이름과 가까워지는 호칭은 기억 상태에서 계산한다. 실제 인물·학교의 평판을 작품에 투사하지 않는다.

## 문장의 리듬과 교정 예시 (이번 게임을 위해 새로 쓴 문장)

**설명 중심**: “혼자서 감당하는 학교는 아니었다.”

**장면 중심**: “이거 제가 봐 둘게요.” 동료가 의자를 내 옆으로 당겨 왔다. 나는 고개를 끄덕였다.

**감정 직접 서술**: “가까워질 기회가 생겼다.”

**감정 간접 서술**: ‘저 지금 근처예요.’ 나는 휴대전화를 한 번 더 읽고서야 책을 내려놓았다.

## 검증·보안

- 코드 구조는 기존 7일·21개 기본 선택·5개 엔딩 및 학교문화 추가 사건의 선택 ID와 수치 변화 계산을 유지한다.
- 배포 전 GitHub Actions에서 전체 이야기 분기·대화 템플릿·개인정보 비저장·가상학교 격리·미인증 Lv2 접근 차단을 검사한다.
- 과거 학교 조사 결과는 승인된 집계만 시나리오의 소재로 사용하고, 2027년 실재 사건으로 확정하지 않는다.
- 실제 문학작품 문장을 그대로 가져오거나 사용자의 이름·게임 선택을 저장하지 않는다.
