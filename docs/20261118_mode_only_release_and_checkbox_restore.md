# 2026-11-18 | Lv.1 학교별 최다 선택값 전용 표시

## 변경 내용
- 운영 Supabase Edge Function `beagu-level-api` v30.
- `school` 응답은 `schoolQuestionModes: [{year,questionId,modeOption}]`만 반환한다. 기존 `schoolDistributions` 및 `roundedDistribution` 페이로드는 중단했다.
- `js/level-search.js`는 학교·문항의 최다 선택값 하나만 표시한다. 보기별 비율·막대그래프·도수는 표시하지 않는다.
- `school-report.html`과 `js/statistics-compare.js`는 동일 모드 필드로 표시한다.
- 학교별 원자료의 비공개 저장소는 유지한다. `anon`/`authenticated` 테이블 직접 SELECT 권한은 금지한다.
- 2026년 공개 승인 및 72시간 지연 규칙은 변경하지 않았다.

## 2025년 복수선택형 문항의 추가 복구
원본: 사용자 소유 Google Sheets `raw_data : 배구지수 시즌3 (2025)`.

모든 원본 보기 문자열을 `js/2025-observed-choices.js`의 원자료 반복 관측 목록과 교차 대조했다.
괄호 안 쉼표는 선택지 내부의 문장부호로 취급하고, 최상위 수준의 쉼표에서만 선택지를 분할했다.
정규화한 시도와 학교명이 한 학교에 유일하게 매칭되고, 해당 학교의 해당 문항에 존재하는 모든 원자료 응답에서 모든 선택지가 검증되며, 최다 선택지가 **유일**한 경우만 적재했다.

| 문항 | 원자료 일치·유일 최다인 학교 수 |
|---|---:|
| Q03 과다업무(교사 행정업무) | 97 |
| Q04 학교행사 | 148 |
| Q30 기피 학년 | 800 |
| 합계 | **1,045개 학교·문항 결과 / 887개 학교** |

보충 자료는 `public.beagu_school_question_modes_supplement_v1`에 비공개 보관하고,
`beagu_school_question_aggregates_v2`에 이미 있는 2025년 승인 집계 학교에 한해서 API가 읽는다.
이 중 응답 행 수가 정확히 하나인 보충 자료는 686건이다(사용자에게 개별 건수 미노출).

### 보류 데이터
- 2025 Q03: 공동 최다 1,267개 학교·문항 사례, 원문 보기 미확인 44개 학교
- 2025 Q04: 공동 최다 1,161개 학교·문항 사례, 원문 보기 미확인 99개 학교
- 2025 Q30: 공동 최다 573개 학교·문항 사례, 원문 보기 미확인 17개 학교
- 해당 문항에서 결측/미응답도 존재하므로 위 수치들의 합이 1,408과 반드시 같지 않다.
- **동률 중 하나를 임의로 선택해 '유일한 최다 선택값'으로 제시하지 않는다.**
- 2023 Q11–Q14, 2024 Q03은 원본 보기와 값의 의미가 충분히 검증되지 않아 보류한다.
- 2023~2025 전체 데이터의 원본과 100% 일치 검증은 수행되지 않았다.

## 개인정보 관련
- 응답 분포를 제거해도 **응답이 1건인 학교의 최다 선택값은 해당 교사의 선택을 추론할 수 있다.**
- 내부 `OWNER_AUTHORIZED_CLOSED_CHOICE` 상태는 서비스 운영자의 공개 지시를 기록한 것이며, 응답자별 구체적 공개 동의나 법적 적합성 확인을 대체하지 못한다.
- 민감하거나 식별 가능한 자유입력, 자유서술 원문, 분포 및 표본수는 API로 보내지 않는다.
- 공개 범위, 응답자 동의 범위, 지역·학교 간 작은 셀 조합에 따른 재식별 가능성은 별도 검토가 필요하다.
