# 36화 남성 누락 인물 점검 — 도윤

- 원고 `js/class-diary-semester-v1.js`와 캐릭터 자료를 대조했다. 기존 성인 한현우, 이준서, 최도현, 장태식은 이미 자산·등장 매핑이 있었다.
- 반복 등장하지만 전용 원화가 없었던 **가상의 3학년 학생 도윤**을 1·4·9·15·20·24·26·32·35화에 연결했다.
- 2×2 실사풍 허구 인물 표정 아틀라스: 기본, 걱정, 미소, 발표하는 모습. 제작 이미지 WebP 최적화 후 동일 출처 경로 사용.
- 도윤이 없는 36화 빈 교실과 기존 7일 체험에서는 자동 숨김. 다른 교직원과 같은 회차에 등장하면 보조 인물을 작게 표시.
- 학생의 괴로움으로 점수나 호감도를 추가하지 않았고, 사진은 특정 실존 학생의 개인정보가 아니다.
- 에피소드 원고, 게임 선택지, 로그인·레벨·학교 API·진행 기록 비저장 구조에는 변경 없음.
