## 코드 적용 전 서버 차단 조건
이 후보는 정적 Pages만 적용할 수 없다. 기존 운영 Edge 함수가 새 계정 RPC를 모르거나 새 Edge 함수가 미설치 SQL을 호출하면 인증 및 기존 열람 경로가 중단될 수 있다.
1. 승인 전: 의존성 및 운영 schema/grants/Edge 버전/기존 공개 파이프라인의 읽기 전용 점검. 기존 관리자 MFA와 유효 추천 실적, 개인 참여번호, 게시물 소유권 및 개인정보 보존 계획 확인. 기존 백업 정책과 복구 리허설 확인. 가입/추천/세션 쓰기 일시 중지 및 복구 창에 대한 명시 승인.
2. 별도 승인된 서버 작업에서만 account-provisional-v1.sql의 트랜잭션 설치와 기존 달성자 스냅샷, 기존 공유코드 만료 시각 확정, account-nickname-cron-v1.sql 설치를 검토한다. account-identity-v1.sql은 현 후보에서 개인정보 수집 구조를 추가하지 않는 주석 파일이다. 비밀번호 pepper(환경변수 BEAGU_ACCOUNT_PASSWORD_PEPPER_V1)는 안전한 비밀 저장소에만 설정하며 출력/커밋 금지. 새 계정 Edge 게이트웨이의 사용자 정의 세션 인증 및 JWT 설정은 격리 검증과 동일한지 확인한다.
3. 승인된 독립 서버 후보에서 계정/관리자/참여/추천/포스트잇/학교 및 게임 보호 경로를 함께 점검한다. 특히 beagu-account-v1, beagu-admin-members-v1, beagu-challenge-identity, beagu-level-api, beagu-postit-api-v1, beagu-referral-link-v1, beagu-2026-civic, beagu-school-culture-v1, beagu-school-interest-v1 및 class-diary-guest-access-v1/story-signals-v1/world-v1. 공개 파이프라인의 새 버전과 겹치는 함수는 파일 전체 교체 금지, 검증된 권한 검사만 병합 후 회귀 검사.
4. 변경 전후 기존 번호·유효 추천·게시물·관리자 및 공개자료의 무결성 비교. 가입 선택 Lv.1, 기존 개인 Lv.2 유지, 신규 이중 미션, 포스트잇 계정 필수, 권한 철회·복구·세션 폐기 시험. 새 계정/글쓰기 활성화 전 실제 승인과 롤백 결정을 확인.
5. 정적 웹 롤백은 SQL/Edge/신규 계정 데이터까지 되돌리지 않는다. 쓰기 활성화 이후에는 새 데이터 삭제/이전 백업 덮어쓰기 금지. 계정 및 글쓰기 일시 중단 등 전진 복구를 우선 검토하고, 불가피한 복원 시 신규 데이터 보존과 호환성·개인정보 재검증을 거쳐 별도 승인한다. legacy Auth/SMS 데이터 삭제는 별도 작업이며 이 버전의 등록·배포 승인에 포함되지 않는다.
