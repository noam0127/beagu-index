# 『난감한 스쿨밴드』 — 008/030 악기별 N레인·키보드·터치 입력 계약

**날짜:** 2026-11-22 KST. **범위:** 원본 `nangam-schoolband_30-step_master_prompt_v1.md` 008/030(원본 031~035). 이번 단계의 명시적 완료 기준은 **4개 악기 × 5개 난이도 = 20개 조합의 모든 레인에 유효한 노트가 있고, 레인-키-노트-터치 연동 자동 테스트가 전수 PASS**하는 것이다.

## 코드 변경

- 게임 소스 `games/nangam-schoolband-v08/index.html`의 기타 레인 실제 표시를 개요와 일치시켰다. 기존 약칭 **파워→파워코드**, **고음→고음 리프**. D/F/J/K 키는 그대로. 캔버스·패드·키 안내가 단일 `INST` 정의를 재사용하게 유지했다.
- 악기 변경 시 캔버스의 `aria-label`에 해당 악기 이름·현재 레인 수·모든 레인의 이름과 입력 키가 나열되도록 갱신한다. 화면에 보이는 버튼 글자·키와 접근성 설명의 불일치 방지.
- 기존의 패드 `pointerdown` 방식은 유지하면서, 키보드로 패드에 포커스하고 **Enter/Space로 활성화한 네이티브 click(detail=0)**도 해당 레인을 타격할 수 있게 했다. 반면 **포인터 클릭(detail>0)**은 이미 pointerdown으로 채점했으므로 click에서 다시 채점하지 않아 중복 적중·오입력을 막는다.
- 원본 창작 교가 선율 28음, `PARTS` 노트 시간표·5난이도 임계치·Web Audio 음색·Supabase 학교 API 계약·오프셋·일시정지 로직은 변경하지 않았다. 운영 `main`과 실제 운영 웹·DB도 변경하지 않는다.

## 검증 설계와 제약

1. `scripts/test-schoolband-stage008.cjs`는 원본 `INST`와 `PARTS`를 실제 HTML에서 추출해 평가한다. 20조합·총 **80개 레인×난이도 연결**을 검사하며, 쉬움 키보드 특정 레인의 노트를 고의로 제거하거나 베이스 Space 물리 키를 중복하거나 드럼에 존재하지 않는 레인을 추가한 **오염 fixture 3종을 반드시 실패로 감지**한다.
2. Chromium PC 1280×850 및 모바일 320×640 두 가지 브라우저 설정 각각 20조합(총 40회): 합성 학교 검색→각 악기 선택→실제 노트 차트 확인→모든 레인의 **첫 마디에서 PC 매핑 키로 한 번**, 두 번째 마디에서 **터치 pointerdown으로 한 번**, 세 번째 마디에서 **패드에 포커스 후 Enter 한 번**→실제 게임 종료 상태 확인. 4+4+3+5 레인 ×5단계 ×2모드로 **키보드 160회 + 포인터 160회 + Enter 40회**를 검증한다.
3. 매 타격은 각 악기/해당 레인의 실제 노트 시간에 맞추고, `getStatus().hits` 증가·정확한 노트 done 플래그로 입력 계약을 확인한다. 비동기 MISS 시각 효과와의 경쟁이 있으므로 순간 배지 텍스트를 입력 성공의 단일 판단 근거로 쓰지 않으며, 실제 시간 축의 PERFECT/GOOD/MISS는 004단계 별도 회귀검사로 유지한다. 포인터에서 이어지는 detail>0 click은 점수나 히트 개수를 추가하지 않아야 한다.
4. **시험의 중요한 한계**: 테스트 시간·호스팅 비용을 줄이고 모든 조합을 끝까지 완료시키기 위해 Chromium 테스트 전용 `AudioContext.currentTime` **가속 시뮬레이션**을 주입한다. 브라우저 이벤트·DOM·차트 판정·완료 처리는 실제 게임 코드를 실행하지만 이는 **실제 18초 음악 청음 또는 물리 입력 지연 측정이 아님**. 선택 악기 사운드 확인은 010~012단계, 물리 멀티터치는 017·027단계 검증 대상으로 유지한다. 해당 테스트에서는 음소거로 오디오 노드 예약 부하를 제외한다.
5. 레인 패드 폭 32 CSS px 이상/높이 68px 이상, 레인별 클릭 영역 겹침 0, 수평 오버플로 0, 캔버스에 키·악기 이름이 실제로 그려지는지 확인한다.
6. 완료 시 점수 양수·실제 종료 결과·100% 진행률·재시작 가능 여부를 검사한다. 전체 결과 `artifacts/schoolband-stage008/results.json`과 PC/모바일 4악기씩 8개 캔버스 화면을 아티팩트로 저장한다.
