# LV.1 학교별 승인정보와 전국·지역 비교 (2026-11-17)

## 원본 및 이름 검증
- 원본: 2025 배구지수 편집본 `최종출력데이터` 시트
- 학교 식별: `public.beagu_edited_school_rows`의 `source_row`, 원본 학교명·시도와 동일한 행만 결합
- Q열: **행정구역 공동주택 평균 공시가격(원)** → `district_housing_price_mean` (2025년 원본 값; 토지 개별공시지가는 아님)
- U열: **2급 정교사 비율** → `junior_teacher_ratio` (2024년 기준, %)
- V열: **남교사 비율** → `male_teacher_ratio` (2024년 기준, %)
- W열: **2023년 9·4 참여율** → `september_participation_rate` (%)
- 응답자 수와 개별 응답 원문은 공개하지 않음

## 데이터 수
- 2급 정교사 비율: 1,441개교
- 남교사 비율: 1,441개교
- 행정구역 공동주택 평균 공시가격: 1,298개교
- 2023년 9·4 참여율: 877개교

9·4 참여율은 학교 인원 규모가 너무 작거나 비율이 0%·100%여서 개인별 행동 추론 위험이 있는 경우 공개 제외. 이는 응답 건수 표시를 없애는 것만으로 재식별 문제가 해결되지는 않기 때문.

## 전국·지역 비교
- 기준: 연도·원본 참조연도·지표가 동일한 **승인된 학교별 값**
- 수치형: 유효한 학교별 값을 학교당 1개로 취급한 **산술평균**(교원 수에 따른 가중평균이 아님)
- 선택형 학교정보(급식장소, 우유급식 등): **최빈 범주**(평균이라고 표기하지 않음)
- 지역: 동일 시도 `sido_standard` 학교
- 비교집단 5개교 미만: 결과 미제공
- 평균이나 최빈 보기 산출에 사용된 학교 수는 외부에 표시하지 않음
- 개인정보 보호: 비공개 원본은 서비스 역할에서만 접근하며, 외부에는 검수한 값만 인증된 API가 반환

## 배포 구성
- `public.beagu_school_report_official_facts`: 검증된 공식 학교정보만 저장
- `public.beagu_official_numeric_comparisons`, `public.beagu_official_category_comparisons`: 익명 접근 불가, 서버 전용
- Supabase Edge Function `beagu-level-api` v14: LV.1 검증 세션 확인 후 해당 학교의 승인값 및 전국/지역 비교 반환
- `js/level-search.js`, `school-report.html`: `우리 학교 / 전국 평균 / 지역 평균`을 나란히 표시
- 2026년 질문/보기: `js/2026-questionnaire-options-v1.2.js`에 전체 Q01–Q50 질문 및 객관식·그리드 원본 보기 저장(Q51 자유서술 제외)
- 2023–2025년 문항 보기는 원전 보고서에서 검증된 것만 별도로 저장(`js/historical-questionnaire-choices.js`): 각각 10/13/20개 항목

## 남은 범위
- 전체 연도 **학교별 최다 선택 보기 및 설문 문항 전국·지역 평균 보기**는 수치·문항·응답 분포에 대한 별도의 검수된 공개 집계가 있어야 표시 가능. 현재 화면에서는 확인 불가능한 값을 임의로 만들지 않음
- 일부 2023–2025년 설문 문항의 원래 전체 선택지 미확인
- GitHub 및 Supabase 변경은 확인됐으나 실제 `baeguindex.com` 배포는 별도 검증 필요
