# 『난감한 스쿨밴드』 — 004/030 콤보·MISS·동시타격·접근성 연출 감사

기준: 30단계 마스터 프롬프트의 004/030(원본 016~020). 날짜: 2026-11-22 KST.
대상: `schoolband-playtest` 브랜치의 `games/nangam-schoolband-v08/index.html`만 수정. `main`, 운영 웹, Supabase DB/Edge Functions는 변경하지 않는다.

## 수정 내역 (실제 코드)

1. **독립 레인 연출**: 기존 중앙 PERFECT/GOOD 표시 외에 `#laneFx` 그리드의 각 레인에 별도 PERFECT/GOOD/MISS/NO NOTE 배지를 두었다. 같은 순간 다른 레인을 판정해도 서로의 텍스트·애니메이션이 덮어쓰이지 않는다. 모든 배지는 `pointer-events:none`, `aria-hidden=true`로 입력과 음성 탐색에 간섭하지 않는다.
2. **콤보**: HUD 숫자는 모든 적중에서 갱신되며, 3콤보/5콤보 및 이후 5의 배수에서만 무대 상단 `#comboFx`를 짧게 보여준다. 모든 타격마다 번쩍이는 방식은 피했다.
3. **MISS vs 빈 입력**: 음원 시간축에서 판정 시간을 초과한 노트는 `miss` 및 `judged`를 증가시키고 `combo=0`으로 리셋하면서 해당 레인에 `MISS` 표시. 눌렀으나 레인에 유효한 노트가 없으면 `emptyPresses`를 증가시키고 해당 레인에 `NO NOTE` 표시. 빈 입력으로 다른 레인 노트를 삭제하거나 MISSED로 집계하지 않는다. 완료 결과에도 `빈 입력 N회`를 별도 출력한다.
4. **시각 접근성**: 콤보는 무대 상단(13%), 각 레인 판정은 중앙 아래(66%)에 배치해 중앙 판정 글자와 겹침을 줄인다. 화면 흔들림은 최대 약 2px에서 0.85px로 제한했다. 레인 발광 알파를 0.40→0.28 이하로 줄이고 흰색 깜박임 역시 0.35→0.22 이하로 억제했다.
5. **모션 감소**: OS의 `prefers-reduced-motion: reduce` 및 UI의 '효과 줄이기' 체크박스가 동시에 적용된다. 줄임 모드에서 파편 생성 0, 화면 흔들림 0, 링 숨김, CSS 변환 애니메이션 제거, 진동 호출 비활성화. 짧은 정적 판정 글자도 타이머(260ms) 뒤 클래스가 제거되어 **화면에 고착되지 않는다**.
6. **진동 옵트인**: `진동 사용`은 기본 꺼짐. 사용자가 직접 켠 경우에만 `navigator.vibrate()`를 호출하며 OS/사용자 모션 감소 시 강제 비활성화. 해당 설정은 브라우저 로컬 저장소 키 `nangam-band-fx-v1`에 `reduce/vibration` 불리언만 저장한다(학교·학생 식별자 미저장). 시스템 모션 줄이기 사용 중에는 체크박스를 강제로 선택/잠그므로 OS 설정을 해제할 수 없다.
7. **음성 안내 절제**: MISS가 연달아 발생해도 `aria-live` 상태 업데이트는 약 0.8초 이상 간격으로 제한한다. 판정 자체는 각 노트마다 계산한다. 게임 시작·중단 시 오버레이와 타이머를 정리한다.

기존 AudioContext 판정식/악기별 소리·학교 조회 API·자작곡 28음·20개 차트 밀도는 변경하지 않았다. 입력 보정·다중동시노트 경계는 005~006에서 별도 집중한다.

## 시험 시나리오와 합격 기준

- 일반 모드: EXTREME 드럼 하이햇 3연타로 콤보 3 달성. 다음 동일 시간의 2레인 노트 2개를 각각 타격해 콤보 5 달성. 두 `laneMessages`가 각각 보이며 수평 영역이 겹치지 않아야 한다. 배지는 터치를 차단하지 않아야 한다.
- NO NOTE: 잘못된 레인 탭의 `emptyPresses`만 증가하고 MISS/콤보는 유지되어야 한다.
- 자연 MISS: 실제 오디오 시간이 늦어서 지나간 미타격 노트의 `MISS` 배지가 보이고 `emptyPresses=0`이어야 한다.
- GOOD: PERFECT 구간 외, 허용 입력 구간 내에서 실제 타격한 노트가 GOOD으로 표시되어야 한다.
- OS reduced motion: CSS 애니메이션 none, 파편 0, 진동 0, 링 none, 판정 텍스트 310ms 후 안 보임. OS 효과 줄이기 해제는 UI에서 불가능해야 한다.
- 수동 옵션: 효과 줄이기 체크/재방문 저장 복원, 진동 기본 꺼짐, 체크 이후에만 진동 호출.
- 별도 `scripts/test-schoolband-stage002.cjs`로 4악기×5난이도 20조합 회귀. 모두 운영 서버가 아닌 가상 학교 데이터로 실행.
