## 3. 관계 설정

- 주인공 ↔ 서지윤: 서류 취합과 교실 규칙 토론에서 시작; 의견을 서로 듣는다면 신뢰와 설렘, 무리하게 다가서면 거리감.
- 주인공 ↔ 한현우: 짧은 농담과 학년 업무 조정에서 시작; 상대의 시간을 존중하는 선택에 따라 친밀도 변화.
- 주인공 ↔ 윤민서: 연애 관계 없는 학년 동료; 상담 절차와 학생 안전을 함께 판단.
- 박수현 ↔ 동학년 교사들: 업무분장표·학년협의회·주안 협의를 통해 책임을 조정.
- 교감·교장 ↔ 동학년: 관행과 절차, 학급의 자율성을 둘러싼 논의. 학교 내 실제 인물이나 학교 평가와 연결하지 않는다.
- 행정실·전담교사 ↔ 담임: 행정 절차와 수업 시간을 각자의 전문성으로 존중.

## 4. 제작 규칙

1. **표준 디자인 잠금**: 각 캐릭터의 머리 윤곽, 얼굴형, 눈매, 평소 의상색을 먼저 고정한다. 동일 인물의 기본·미소·걱정·화남·당황·피곤·수줍음·자료를 든 자세로 변주할 때 변경하지 않는다.
2. 배경을 글자·로고·안내문 없는 독립 이미지로 제작하고, 이름·대사는 HTML에만 작성한다.
3. 비주얼 소스: 현재 웹에 연결된 것은 네트워크 없는 SVG 일러스트(장면 배경과 인물 초상 분리). 이전 대화에서 만든 고해상도 그림·실사형 시안은 참고 자료이며 **정식 게임 에셋으로 아직 배포되지 않음**.
4. 배경의 공간 목록: 교문, 교실, 학년연구실, 교무실, 복도, 상담 공간, 퇴근길, 카페·서점, 일요일 집 책상. 현재 SVG 장면은 원본 대본의 장소 태그와 연동.
5. 2027년 3월 8~14일 7일 이야기와 21개 기본 선택, 다섯 엔딩은 유지. 추가 업무·학교문화 사건도 순수 가상으로 표현.

- 심리·장면에 따라 일상(Simplicity), 농담(Ice Cream), 학생 참여(Amberlight), 갈등(Intervention), 설렘(Moonlight), 휴식(Castles in the Sky), 성취(Felicity), 엔딩(Home Was You)을 배치한다.

- 효과음은 Web Audio 오실레이터 기반의 독창적인 부드러운 합성음. BGM과 효과음 음량은 별도 조절.

## 8. 주인공 설정 간소화 · 이름 호칭 · 학교 자료 연동 (2026-11-20)

- 주인공 입력은 **이름(한글 2~8자), 나이, 교직 경력(저경력·중간경력·고경력), 성별, MBTI, 관계를 쌓을 동료**의 6개만 노출한다. 업무분장·교직문화·학년·체육 모임·지역 설정 UI는 제거했다. 교직 경력은 사용자가 저경력·중간경력·고경력 중 하나를 선택하며 정확한 연차를 요청하거나 저장하지 않는다. 각 단계에 맞게 독백과 가상 업무 장면만 달라진다.
- 실명 여부는 확인하지 않으며 이름은 브라우저 메모리에서 해당 회차 진행 중에만 사용한다. 새로고침 시 이름·선택·진행·엔딩이 사라진다. 이름을 서버로 전송하거나 저장하지 않는다.
- 동료가 부르는 호칭은 초기 **'최윤호 선생님'**과 이후 친밀해진 **'윤호 쌤'**의 두 단계다. 이야기의 3일차 이후 신뢰·호감도가 함께 높을 때만 자연스럽게 줄어든 호칭을 사용한다. 이 호칭은 MBTI·성별과 무관하다.
- 교직생활 묘사: 기존 21개 기본 선택지 + 추가 학교생활 사건 선택지 37곳의 문장을 실제 한국 교사들이 이야기할 법한 일상어로 다듬었다.
- 공개 승인된 학생 수(해당 연도)로 학교 규모를, 승인된 공식 주소/지리 태그로 읍·면/동 지역 배경을 반영한다. 공개 대상이 아니거나 부정확한 값은 사용하지 않는다.
- 교직 경력은 나이·2급 정교사 비율에서 유추하지 않고 사용자가 경력 구간을 직접 선택한다. 담당 학년은 가상 시나리오의 3학년이다. 아래 '9. 역사적 설문' 규칙에 따라 업무배정·동료 관계 관련 **창작 사건**을 바꾸되 실제 배정 담당자나 학교의 현재 교직문화를 판정하지 않는다. 이 값들이 실제 해당 학교 교사의 속성을 뜻하지 않는다.
- 로그인 없는 체험판은 **가상학교 자료만 사용**하며, 현실 학교 데이터에 대한 우회 조회 경로가 없다.

## 9. 승인된 역사적 설문 기반의 업무·갈등 사건 분기 (2026-11-20)

- **데이터 경로**: 기존 Supabase 레벨2 전용 `class-diary-story-signals-v1` → `selectSignals` 검증 → `scenePlan.fictionalContext` → `inferredProfile` → 업무·회의·친목 **가상 장면**. 인증 우회나 새로운 DB 저장 없음.
- **승인 기준**: 학교 ID·공개 조사 연도 일치, 공개·검증된 문항별 최다선택 집계, 엄격한 검토 정책 `N10_CELL3_PATTERNS5_STRICT_MATCH`, 2026년 수동 공개 승인, 민감 문항 제외. 일반 공개 범위와 게임에 사용하는 검토 기준은 별개이며, 1건 공개만으로 학교 문화 판정을 만들지 않는다.
- **업무분장**: 2026년 Q08(저연차·전입자에게 특정 업무를 우선 배정)에서 검증된 최다선택 결과가 ‘그렇다’ 또는 ‘매우 그렇다’일 때, 특히 저경력 주인공이 업무배정에 대해 의논하는 **창작 사건**을 사용한다. 실제로 해당 업무를 주인공에게 배정한 사실로 표현하지 않는다.
- **의견·협의**: 2026년 Q04(의견 표명 시 압박 우려), Q06(배정 기준 공유), Q07(기준의 일관성), Q08, Q09(조정 가능성) 중 우려 방향의 **서로 다른 문항이 적어도 두 개** 있고 그중 업무배정 관련 우려가 확인되면 업무 조정이 필요한 **가상 관계 분기**를 선택한다. **단일 문항 또는 중립·모름** 응답으로 갈등이 발생한 학교라고 설정하지 않으며, ‘적대적 학교’ 판정을 자동 생성하지 않는다.
- **친목**: 2026년 Q01(모임 불참 의사 수용)이 ‘전혀 그렇지 않다’ 또는 ‘그렇지 않다’로 검증된 경우, 자유로운 참여 여부를 의논하는 창작 사건의 소재로 삼는다.
- **그 밖의 연도**: 2023~2025년 공개 승인 자료는 기존의 주제별 장면 생성에서 계속 활용한다. 연도마다 선택지의 의미가 다르므로 다른 연도의 단어·보기 점수를 2026년 평가척도로 강제 변환하지 않는다.
- **미승인·누락·체험판**: 미공개 결과, 검증 미달, 로그인 없는 가상학교 체험판은 관련 신호를 사용하지 않는다. 일반적인 허구 학교생활 장면만 이용한다.
- **면책·표시**: 학교별 과거 집계는 2027년의 현황이 아니며, 실제 교직원 또는 행정실 직원의 언행·책임·갈등 여부를 입증하지 않는다. 게임 안내문에 창작 사건이라는 점을 지속적으로 드러낸다.
- **저장 금지**: 이름·경력·선택·게임 점수·결말·화면 효과음 설정을 로컬 또는 서버에 저장하지 않는다.
