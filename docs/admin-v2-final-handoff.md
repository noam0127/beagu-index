- 운영 DB 조회 당시 `beagu_postit_member_accounts` 0행: 실제 회원 연결 E2E 미검증.
- Lv1 상태는 현 관리자 API에서 완전히 판별되지 않음.
- Auth 계정 정지와 감사 기록 저장이 비원자적: 감사 기록 실패 시 경고하지만 사후 조정 필요.
- 서비스 역할로 실행되는 SQL RPC와 Edge Function은 별도 보안 테스트 필수.
- 4천·1만 건 테스트는 합성 계산 중심, 실제 부하 테스트 미실시.
- SQL 마이그레이션 미적용이므로 관리자 통계/목록 RPC 운영 호출 불가 가능성.
- 정적 테스트 파일을 작성했으나 전체 테스트 실제 실행 미확인.
