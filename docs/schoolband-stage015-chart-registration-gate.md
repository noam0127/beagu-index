# 『난감한 스쿨밴드』 015/030 — 자동 악기별 20개 차트·곡 등록 품질 게이트

**근거:** 사용자가 제공한 원본 30단계 마스터 프롬프트 015/030(원본 057~060). **검증일:** 2026-11-22 KST. 이번 단계는 014 편곡에서 생긴 음악 이벤트를 **실제 플레이 가능한 4악기×5난이도 노트로 변환**하고, 출처·곡 버전·박자·노트 밀도·타이밍·화성·권리·검수 이력의 **등록 전 품질 게이트**를 정하는 작업이다. 직접 창작한 원곡 한 곡의 20조합은 실제 Chromium 게임 판정기로 연주 검증한다.

운영 불변 조건: GitHub `noam0127/beagu-index` **`schoolband-playtest` 시험 브랜치만** 수정한다. `main`, `baeguindex.com`, 운영 Supabase DB/Edge Functions, 다른 게임, 기존 학교 교가·설문·교사 자료는 변경하지 않는다.

## 실제 구현

1. `scripts/schoolband-chart-generator-v1.cjs`: 014단계 록 편곡의 버전·SHA256·원본/권리 상태·파트/멜로디·시간축을 먼저 검증한다. `arrangerVersion:schoolband-rock-arranger-v1.0.0` 외에는 거부한다.
2. 음악 이벤트(오디오 소스의 `part,role,pitch,startTick,startSeconds,playbackSeconds,durationTicks`)를 **기타 4·드럼 4·베이스 3·키보드 5 레인**으로 결정적 매핑한다. 사용자에게 맞는 악기별 음색 레인과 소스 악보 사이의 대응을 각 노트 `source`에 보존한다.
3. 3중 동시타격을 만들지 않는다. 실제 기타 power-root/power-fifth 두 음, 키보드 3음 코드에서는 **2개 레인 연주로 감축**하고 자동 반주는 원 코드 3음 자체를 유지한다. **드럼 탐**은 끝부분 스네어를 탐으로 변환, **기타 고음 리프**는 마지막 2마디의 파워5도를 1옥타브 올려 재배치한다. 이러한 음색/음정 변환은 `transform` 필드에서 `snare_to_tom_fill`·`fifth_to_high_riff`로 명시하여 임의 무단 편집을 숨기지 않는다.
4. 차트 난이도 `easy/normal/hard/very_hard/extreme`는 선택 비율 30%/45%/61%/78%/100%를 시작점으로 사용하며, 각 레인의 **최소 1개 노트**를 EASY부터 포함한다. 난도가 높을수록 포함되는 노트가 증가하며, 이전 난이도 노트는 후속 난이도에서 보존한다. 음표의 `startSeconds`는 실제 편곡 음악의 `startSeconds`와 **완전 일치**하도록 보존. 인간화 타격 시차는 자동 반주에서만 ±4ms 범위로 유지한다.
5. `schoolband-chart-catalog-v1.0.0` 구조에는 오디오 이벤트 전량, 노트별 실제 소스, 악기/레인, 20차트, 마디·BPM 변화, 배열 길이, 판정 타이밍, 원곡 권리 및 변환 체인 SHA를 저장한다. 난이도 전수 `validateCatalog`은 사후에 노트 음정·시각·레인·중복·점수 대상 노트 유무·난이도 증가·최대 2개 동시·SHA 일치·비공개 상태를 다시 검사한다.
6. 각 차트 등록 결과를 `registration.status=qa_passed_private`, `publicApproved=false`, `publicRelease=false`로 고정. 감사 기록 `generated → reviewed → private_trial_approved` 3개를 파일에 남긴다. `requestPublication` 함수는 무조건 **공개 차단**한다. 실제 학교 교가의 허가·삭제·공개 승인 등은 022~023단계 미완료이며, 이 파일은 학교 실제 게시 기능이 아니다.
7. `games/nangam-schoolband-v08/index.html`: 내부 QA 호출 `window.nangamSchoolbandV08.loadGeneratedTrial(catalog, instrument, tier)`을 추가했다. 기존 사용자/학교의 원래 내장 차트는 그대로 동작하며, **정해진 내부 창작곡 ID**, 비공개 등록 상태, 편곡 길이·8마디 4/4·단일108BPM의 유효성 조건을 모두 통과해야만 이 시험 재생 경로를 연다. 실제 원곡의 노트 시각·레인·피치를 동일 게임 판정기(`makeChart`, `hit`, `animate`)로 연결한다.
8. 내부 QA 모드의 음악은 014단계 편곡의 **실제 5개 파트 이벤트**를 `scheduleAhead`에서 원곡 기준으로 예약하고 선택한 악기는 자동 반주에서 제외한다. 사용자가 실제 누른 악기의 음악 이벤트 `pitch`를 사용해 해당 소리를 발생시키고, `getAudioEvents`로 `source:auto/hit/miss`을 기록한다. 사용자가 공개 웹에서 곡을 게시·계정을 등록·학교 실제 교가를 끌어오도록 하는 기능은 없다. 현재 게임의 기본 내장 차트/음악 엔진/운영 정보는 미변경.
9. **복합 박자 4/4·3/4·6/8·5/4 곡은 같은 생성기에서 20차트 품질 게이트를 통과하지만 아직 기존 108BPM 고정 런타임 게임으로 연주시키지 않는다.** 014단계에서 보장한 복합 시간축을 임의 108BPM으로 잘못 재생하지 않도록 실제 로더가 거부한다. 020단계 이후 곡별 자동 변속/레인 UX 및 022~023 권리·공개 승인와 구별해야 한다.

## 검증 방식

`scripts/test-schoolband-stage015.cjs`은 다음 세 계층을 수행한다.

- **음악학·데이터 품질:** 014단계 원곡(원본 28음, 편곡 음향 이벤트 200개)과 복합 박자 자체 창작 연습곡(원본 28음, 편곡 음향 이벤트 185개)을 각각 4악기×5난이도 **총 40개 차트**로 생성하고 모든 노트를 실제 원래 음악 이벤트 `part,role,startTick,pitch`과 비교. 파생 노트는 변환 메타데이터를 필수로 남기고 최대 동시타격 2개, 전 난이도 전 레인 노트, 엄격히 증가하고 계승되는 난이도 밀도 확인.
- **오염·권리 거부:** 변형된 곡 SHA, 권리 미승인, 오디오-차트 타이밍 변조, 피치 변경, 중복 노트, 빈 레인, 난이도 역전, 부정 등록 상태·검수 이력 누락, 실제 공개 호출을 의도적으로 실행해 **거부 여부를 실패 주입** 검사. 실제 데이터를 등록·발행하지 않는다.
- **게임 실재생:** Chromium 데스크톱(1280×850)과 모바일 320px 터치 뷰포트에서 창작 원곡의 **4악기×5난이도 = 20개**를 각각 내부 QA 모드로 불러온다. 모든 노트의 현재 게임 차트 `t/pitch/lane`을 원본 음악 이벤트와 1:1 대조한 뒤, 모든 레인의 실제 **KeyboardEvent 키 입력**, 점수 증가 및 Web Audio `hit` 로그를 확인하고 17.78초 곡 끝까지 자동 게임 진행. 합계 40개 연주 완료. 공개 차트/권리 미확인·변속 곡은 해당 고정 BPM 라이브 QA 경로에서 차단.
- CI `.github/workflows/schoolband-stage015.yml`: 신규 순수/브라우저 시험, 014 편곡·008 악기 N레인·005 판정 경계 회귀, 두 자체 창작곡의 **비공개 QA 카탈로그 JSON**과 검수 이력/테스트 로그를 보존.
