# 『나의 OO한 학급일지』 36화 한 학기 본편

구현: 2026-11-20 · 2027년 3월 8일~7월 16일 가상 초등학교.

## 범위
- 6부×6화 = 36화, 각 3선택지(108개). 3인물(서지윤·한현우·윤민서)의 부별 말과 거리감 변화.
- 한국 현대소설에서 사용되는 장면 중심의 자연스러운 한국어 서술, 절제된 대사, 작은 행동과 침묵의 감정 표현을 모두 자체 창작했다. 특정 작품 문장을 복제하지 않는다.
- 서아와 도윤, 학급회의·줄서기·모둠·공개수업·업무분장·안전사고·보호자 상담·동료와의 오해가 계절을 따라 연결된다.
- 3월 선택이 4·5·6·7월의 장면에 다시 반영되는 장기 회수 장면. 세 주요 성인 동료의 특성이 달라, 같은 사건도 관계가 다르게 형성된다.
- 결말은 5종(소중한, 든든한, 단단한, 다정한, 솔직한). 윤민서 경로는 연애 결말 없음.
- 기존 7일 체험은 그대로 유지. 오프닝에서 36화 본편 또는 7일 체험을 선택.
- 현재 분량은 **36화 초판 원고**이며 추후 회차별 서브 사건, 복수의 선택 후 장기 분기를 확장할 수 있다.

## 주요 구성
1. 낯선 이름들 (3월): 이름표, 복합기, 학생·학년의 첫 관계
2. 우리 반이라는 말 (4월): 자치 규칙과 안전, 학생의 질문
3. 좋은 사람의 기준 (5월): 기록과 보호자 전화, 서로 다른 동료
4. 소문이 지나간 자리 (6월 전반): 안전사고 대응·상담·회의
5. 서로의 편이 된다는 것 (6월 후반~7월 초): 회복·공개수업·교사의 휴식
6. 여름방학 전날 (7월): 이전 결정의 결산과 관계의 변화

## 코드와 검증
- 원고·상태 엔진: `js/class-diary-semester-v1.js`
- UI: `teacher-class-diary-play.html`의 `semesterStart` 버튼 및 `renderSemester`
- 테스트: `scripts/test-class-diary-semester.cjs`와 `scripts/test-class-diary-browser.cjs`.
- `class-diary-world-validation.yml`에서 분기와 개인정보 비저장 정적 검사, `class-diary-browser-e2e.yml`에서 모바일 전 회차 실제 클릭, `class-diary-production-smoke.yml`에서 배포 파일 해시 비교 수행.

## 개인정보·저작권 원칙
- 실제 학생, 학부모, 교직원·학교의 사건을 진술하지 않는다. 학교 선택 정보는 기존 Lv2 승인 정보 조회 경계 안에서만 활용하며, 36화 자체는 창작된 일화이다.
- 게임의 프로필·선택·호감도·진행 상황을 저장하거나 별도의 API로 전송하지 않는다. 새로고침하면 진행이 사라진다.
- 학생의 어려움은 호감도 보상으로 사용하지 않는다. 성인 간 로맨스 역시 상대의 의사를 존중하며 결말을 강제하지 않는다.
