bootstrap-preparation-v1.json의 11개 핵심 파일 blob은 검증 SHA에서 직접 확인했다. 나머지 파일도 동일한 불변 커밋에서 취득한다. 검증 스크립트는 로컬 Git 객체 및 작업트리만 읽는다. 운영 SQL, Edge 배포, secrets 설정, Pages 실행, main 병합, Vercel 금지. 2026 열람 정책, Lv.3 제외. 모든 실행 gate 유지. 운영 연결 완료로 간주하지 않는다.

## 운영 제어 연결 구현 후보
- 기존 fixture 파일과 검증 SHA 보존. 별도 production candidate SQL은 설치 승인 설정/운영 SHA/활성 큐 precondition을 요구하고 기본 gate=false, service_role은 gate 변경 불가. 운영 scope/테이블/RPC/legacy lock 분리. 최종화·복구 실행은 독립 관측자 및 운영 복구 승인 연결 전 차단.
- 기존 MFA/manifest/recipe 검증과 OIDC worker 검증 재사용, production 전용 audience와 명시적 env gate, 별도 registry, 고정 workflow SHA. Python scoped runner와 생산 제어 ledger 연결 구현. 운영 transport는 미연결이며 실제 worker/publisher wiring, provider 및 durable backup/observer는 추가 준비 필요. 기존 단일 Pages publisher 미변경. UI 잠금 유지. CI에서 실제 disposable PostgreSQL 설치 실패/기본 잠금/권한/claim/backup/실패 중단을 검사한다. 운영에 설치하거나 활성화하지 않는다.

- 작업자 연결 코드: 고정 운영 제어 endpoint, 단일 TLS 요청, 전용 GitHub OIDC audience, 응답 크기 및 action 제한. 기본 compile-time gate=false, CI는 합성 HTTP와 독립 DB만 사용. actual credential/activation 미검증. production finalization/recovery 및 공급자 실행은 여전히 차단한다.
