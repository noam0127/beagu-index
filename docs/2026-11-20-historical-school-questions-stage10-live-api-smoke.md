## 이번 점검의 정확한 범위

8~9차에서 남은 **실제 네트워크 테스트 병목**을 해소했다. 일반 로컬 작업 환경에서는 DNS 조회가 실패했지만, Vercel의 임시 테스트 환경(네트워크 허용 도메인을 운영 사이트와 Supabase API로 제한)을 사용하여 HTTP GET/POST를 실제 수행했다.

중요한 구분: 실제 운영 웹사이트, API, 데이터베이스, 인증 권한을 통해 검증한 **실제 HTTP 연동 테스트**이다. Chrome 등 실제 렌더링 브라우저를 조작한 **화면 E2E는 아님**.

## 2. 레벨1 임시 세션을 사용한 운영 API 실제 요청

검증용으로 운영 DB `public.beagu_level_sessions`에 강력한 난수로 만든 **5분 만료 레벨1 임시 테스트 세션을 1개 생성**했다. 생성한 임시 세션은 기존 일반 사용자 계정이나 실제 인증코드를 변경하지 않았다. 세션 문자열과 SHA-256 다이제스트는 보고서/저장소에 저장하지 않았다. `X-Beagu-Session` 헤더로 실제 Edge Function에 HTTP POST를 보내고 각 학교·연도의 `schoolQuestionModes` 개수, 반환 level, 승인된 결과 형식 및 민감한 카운트 필드 유무만 확인했다.

| 학교 ID | 연도 | 레벨1 API HTTP | 해당 연도 문항 수 | 기대 문항 수 | 판정 |
| --- | ---: | ---: | ---: | ---: | --- |
| `7551084` 경기 성수초(성남) | 2024 | 200 | **13** | 13 | PASS |
| `9091232` 경남 진영장등초 | 2024 | 200 | **13** | 13 | PASS |
| `7882030` 강원 남산초(홍천) | 2025 | 200 | **47** | 47 | PASS |
| `8181034` 충남 신리초(아산) | 2023 | 200 | **0** | 0(식별 보류) | PASS |
| `9151011` 경남 삼성초(양산) | 2024 | 200 | **0** | 0(전 문항 동률) | PASS |

5개 응답 모두 `level=1`이었고, 각 학교 응답의 `schoolQuestionModes`에 `validRows`, `source_rows`, `respondents`, `timestamp` 등의 원본/카운트 필드가 없는 것을 직접 검사했다. 특정 선택값 문구 자체를 로그에 출력하지 않았으며 원본 응답자를 특정할 수 있는 필드도 출력하지 않았다.

**테스트 종료 후 임시 세션 1개를 운영 DB에서 명시적으로 삭제했고, 최종 SQL 조회에서 동일한 테스트 세션이 0개임을 확인했다.** 세션을 회수하지 못한 상태로 남겨두지 않았다.

## 3. DB 불변성

테스트 도중 문항 집계 테이블 `beagu_school_question_aggregates_v2`은 추가·수정하지 않았다. 마지막 운영 SQL 재조회:
- 승인 학교·연도 **7,801건**
- 저장된 문항별 단독 최다 선택값 **143,628개**
- 추가 복구 또는 학교 ID 재매핑 **0건**

7차 복구된 73문항은 단순 DB에 존재하는 데 그치지 않고 실제 레벨1 Edge Function 응답까지 모두 도달했다.

## 4. 남은 검증 범위와 프라이버시 과제

- **브라우저 화면 E2E 미검증**: 실제 Lv1 화면의 연도 탭 표시, 원문 보기와 일치하는 UI 출력, 모바일 반응형, 사용자 클릭 흐름은 실제 브라우저에서 확인하지 않았다. 임시 테스트 환경에 Chrome/Playwright 등이 설치되어 있지 않았고, 작업 도중 테스트 환경의 짧은 실행 수명이 종료됐다.
- **실제 계정의 참여코드 로그인 흐름은 미검증**: API 테스트는 DB 임시 세션 직접 생성 방식이므로 참여코드를 입력해 세션을 발급받는 UI의 정상 작동까지 증명하지 않는다.
- **개인정보 검토 별도**: 한 명의 응답으로 특정 학교의 문항별 보기 묶음을 표시하는 것은 항목별 소속을 아는 관계자에게 응답패턴을 추론하게 할 가능성이 있다. 카운트 미노출이나 레벨1 인증만으로 동의·재식별 위험 문제가 완결되는 것은 아니다.
- 신리초 아산/홍성 학교 소속 근거 부재, 삼성초 전 문항 동률은 기존과 같이 연결 보류한다.
- API/프론트엔드 및 DB 보안 정책을 변경하지 않았다.

**10차 결론: 운영 도메인 정상 HTTP 200, 비인증 상세 API 401 차단, 임시 레벨1 인증 세션으로 3학교 복구 73문항 실제 HTTP 반환 및 보류 2건 0문항을 직접 확인했다. 임시 세션 폐기 확인. 브라우저 렌더링 E2E는 아직 별도 과제다.**
