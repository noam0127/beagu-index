## Findings
- postit.html already uses the locker-room title in this base.
- beagu_postit_posts is the sole proposed canonical post store; existing school, game and comparison subjects and post IDs are retained. No copy/backfill of body data.
- Existing Post-it API checks Lv2 and a linked legacy account for writes. The separate anonymous-account integration candidate protects reads as well. The two histories have diverged; never merge the entire earlier candidate blindly.
- The atomic create_post_v2 RPC accepts 200 characters and only school/game/comparison. The subject constraint also rejects general posts. Merely changing HTML maxlength would not work.
- Existing reactions and comments are reusable. No confirmed existing reply-parent, thread position alias, verified operator flag, notification store or general post schema.
