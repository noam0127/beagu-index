# 『나의 OO한 학급일지』 6단계 — 성인 동료 인물별 서사 분화

작성: 2026-11-20. 실제 GitHub main 배포 코드 기준.

## 목표와 범위
기존 7일(2027년 3월 8~14일), 기본 선택지 21개, 추가 학교생활 사건, 점수와 엔딩 5종, 학교별 승인 데이터와 레벨2 접근 제한은 유지한다. 이름만 바뀌던 동료 대사를 **세 사람의 독립적인 한국어 소설 서사**로 분화한다.

### 1. 서지윤 — 차분한 경청과 어른의 호감
- 30세, 3학년 담임. 말끝을 서두르지 않고, 다른 사람의 결정을 대신하지 않는다.
- 주안·학급회의·보호자 상담에서 경청과 분명한 질문으로 관계를 쌓는다.
- 호감과 신뢰가 모두 높아진다면 교문 밖 걷기나 주말 책 이야기에서 미묘한 감정이 드러난다. 일터에서 상대의 거절권과 업무 경계를 존중한다.

### 2. 한현우 — 농담 뒤의 진심
- 32세, 3학년 담임. 평소에는 가벼운 농담으로 말을 열지만 진지한 순간에는 상대의 말을 끝까지 듣는다.
- 학교생활·주안·교문 밖 산책·주말 카페에 다른 대사와 선택 반응을 제공한다.
- 관계가 가까워질수록 농담을 잠깐 멈추는 순간이 등장한다.

### 3. 윤민서 — 관계의 중심은 우정
- 29세, 3학년 담임. 메모와 확인을 중시하는 동료.
- 실제 이름 `민서 선생님`으로 소개하고 대화한다. 연애를 전제로 하지 않는다.
- 업무 협력·학급회의·메모·책 추천 등에서 우정의 지속과 깊이를 표현한다.
- 민서 경로는 기존 소설 엔진의 `warm`, `tender` 연애 엔딩에 진입하지 않는다.

## 실제 구현
- `js/class-diary-character-routes-v1.js`: 세 인물의 각각 다른 7일 장면(21개), 5일 동안의 인사말(15개), 3단계 거리감 변화(9개), 핵심 선택 반응, 엔딩 5종×3개, 추가 가상 사건 연결 문장. 브라우저 저장/API 없음.
- `js/class-diary-director-v1.js`: 기존 7일 분기 후속 서사를 유지하며 인물별 서술·대사·선택 후 반응·결말을 추가한다.
- `teacher-class-diary-play.html`: 새 모듈 로드, 인물 소개와 가상 사건 묘사 적용, 민서 우정 중심 선택 표시.
- `js/class-diary-play-v1.js`, `js/class-diary-scenario-v1.js`, `js/class-diary-incidents-v1.js`: 우정 경로 동료를 ‘동학년 선생님’ 대신 실명 `민서 선생님`으로 안내.
- `scripts/test-class-diary-character-routes.cjs`: 세 경로×7일, 매일 다른 장면, 인물별 선택 반응 및 엔딩, 순수 로직·비저장 검사.
- `scripts/test-class-diary-browser.cjs`: 데스크톱 지윤, 모바일 현우, 모바일 민서 세 경로를 체험판에서 끝까지 진행, 엔딩 및 재설정 검사.
- GitHub Actions에 새 로직의 회귀 검사와 운영 서버 파일 일치 검사 추가.

## 안전 및 문학적 기준
- 현대 한국 소설의 장면·대사 리듬을 참고하되 기존 상업 소설 문장을 복제하지 않고 전부 창작했다.
- 연애 관련 인물은 **성인 교사만**이며 학생은 연애 대상이 되지 않는다.
- 성별, MBTI, 나이를 근거로 인물의 능력이나 선택 결과에 불이익을 주지 않는다.
- 구체적인 학교의 공개 승인 자료는 기존 Lv2 권한과 검증 규칙 안에서 가상 배경 소재로만 활용한다. 실제 학교 직원의 성격이나 관계를 추정하지 않는다.
- 이름·선택·관계 점수·게임 진행·결과를 로컬 저장소나 서버에 저장하지 않는다.

## 남은 개선 가능 사항
현재 삽화는 분리된 SVG 기반이다. 고해상도 정식 일러스트 자산과 실기기 Safari 음향 재생 확인은 별도 후속 작업이다.
