# 2026 배구지수 실시간 비공개 집계 연동 (운영자 설정)

## 구현 상태
- PostgreSQL `public.beagu_2026_public_progress` 테이블: **비공개 내부용**, 익명 및 일반 사용자 SELECT 권한 없음. 전국 접수 건수만 내부 저장
- Supabase Edge Function `beagu-2026-public-count-ingest`: 서버에서만 호출하며 비밀 토큰 검증
- Google Apps Script `scripts/beagu-2026-noon-sync.gs`: 비공개 재집계 성공 후 **전국 공식 응답 건수만** 푸시
- 홈페이지의 설문 응답 건수 위젯 및 스크립트는 제거되었습니다. 내부 집계는 공개 페이지에 표시하지 않습니다
- 기존 챌린지 순번/XP 및 유효 **교사 수**와는 서로 다른 지표

**주의:** 소스 파일 커밋과 Edge Function 배포만으로 Google Apps Script가 설치되는 것은 아닙니다. 이 문서의 설정을 해야 자동 갱신이 시작됩니다.

- 교사 고유 인원, 학교별 결과, 특정 문항 응답, 공식 백분위가 아닙니다.
- 실제 트리거 설치 후에는 전체 원본을 다시 집계하여 최신 건수로 덮어씁니다.

## 2. Google Apps Script 실제 설치
1. 먼저 기존 설치 스크립트·트리거 목록을 백업·확인해 중복 실행을 피합니다.
2. 기존 코드와 충돌하지 않게 GitHub의 `scripts/beagu-2026-noon-sync.gs` 최신 내용을 반영합니다. 다른 파일에 같은 이름의 함수를 중복 선언하지 않습니다.
3. Apps Script 함수 목록에서 **`installBeagu2026Sync`** 를 선택해 **한 번 실행**하고 Google Sheets·외부 요청 권한을 승인합니다.
4. 이 함수는 두 비밀키 설정 여부를 검증하고, `onBeagu2026FormSubmitted` 설문 제출 트리거와 `refreshBeagu2026Stats` 정오 백업 트리거를 중복 없이 설치합니다.
5. 트리거 설치가 확인되면 기존 공식 시작일(2026-11-01) 기준으로 초기 **비공개 집계**를 실행합니다.
6. Apps Script 실행 로그와 비공개 MASTER `정오_실행로그`에서 `SUCCESS` 및 백엔드 동기화 `PUBLISHED` 상태를 확인합니다. `SKIPPED_NOT_CONFIGURED`면 토큰 미설치, `PUBLIC_ERROR`면 서버 연결·토큰 값을 점검합니다. **PUBLISHED는 내부 저장 성공이며 대외 공개가 아닙니다.**
7. 설치한 트리거는 Apps Script 왼쪽 '트리거' 메뉴에서 직접 확인합니다. 이 프로젝트 코드를 GitHub에 저장한 것만으로 실제 설치된 것이 아닙니다.

## 3. 검증
- 원본 Sheet 공식 시작일: **2026-11-01**. 시범 응답(이전 날짜) 제외.
- 응답 **행수**를 집계하며 동일 Google Forms 응답 이벤트가 두 번 전달되어도 원본 전체를 다시 세기 때문에 같은 행이 중복 추가되지 않음. 단, **동일 교사가 서로 다른 응답 행을 중복 제출**한 것은 별도 신원 검증 없이는 구분 불가합니다.

## 4. 공개 범위와 제한
- 공개: 응답자·응답 건수는 공개하지 않습니다. 검수·승인된 비식별 지표에 한정합니다.
- 비공개: 학교명/학교 ID, 답변·선택지, 개별 문항 수치, 특이 학교 기록, 자유서술 및 응답 원문.
- 원본 설문과 비공개 집계 MASTER는 공개 공유하지 않습니다.
- 학교별 문항 공개는 별도 자료 신뢰성·재식별 검토 및 승인 정책을 거쳐야 합니다.
- 이 내부 테이블에는 개인정보나 특정 학교 응답 원문을 저장하지 않습니다.
- 비밀 토큰이 누출되면 **두 곳 모두 교체**하고 이전 토큰을 폐기합니다.
