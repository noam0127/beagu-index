# v1.11.4 물길 — 소유자 설치 및 복구 검증

상태: 개발용 문서. 운영 적용 승인 전에는 설치·집계·트리거 수정 금지.

## Q45 문구 변경 확인 완료
소유자가 2026-11-23 저녁(KST) '교사용'을 삭제했고 조사 의도·응답 기준은 동일하다고 확인했다. 변경 이력은 `docs/2026-q45-wording-history.md`에 기록한다. 최신 코드북은 '와이파이', 정확히 일치하는 두 과거 문구도 같은 행에서만 허용한다. 다른 문항 및 승인 조건은 그대로 유지한다.

## 운영 적용 승인 이후 순서
1. 현재 Google Apps Script 전체 파일·트리거 목록과 운영 백업을 보존한다. 기존 추천 트리거와 추천 파일은 그대로 둔다.
2. 서버 적용 담당자는 격리 환경에서 `supabase/2026-waterway-run-telemetry-v1.sql` → `supabase/2026-waterway-admin-status-v1.sql` → 기존 `beagu-2026-results-ingest`, `beagu-2026-review-admin` 함수 순으로 준비한다. 운영 적용은 별도 승인 이후에만. 인증 토큰을 바꾸지 않는다.
3. 원본 응답 시트 > 확장 프로그램 > Apps Script에서 기존 집계용 Code.gs와 MBTI_Review.gs만 승인된 버전으로 교체한다. 추천 코드·기타 함수가 같은 파일에 있으면 보존하고 집계 함수만 병합한다. 동일 이름 중복 금지.
4. 기존 SUPABASE_PUBLISHABLE_KEY 및 BEAGU_2026_INGEST_TOKEN의 존재만 확인한다. 비밀값 공유 금지.
5. `previewBeagu2026Waterway`는 읽기 전용으로 원본/학교정보를 조회하고 현행 집계 요약만 출력한다. 승인 이후 소스 저장 시 수동 실행해 검토한다. 미리보기는 실제 전송하지 않는다.
6. 기존 제출·정오 집계 트리거가 각각 하나씩 있으면 설치 함수를 다시 실행하지 않는다. 없거나 중복이면 승인 이후 `installBeagu2026Sync`로 해당 두 트리거만 정리한다. 이 함수는 즉시 실제 집계도 실행한다.
7. 트리거가 정상이라면 승인 이후 `refreshBeagu2026AllPrivateStats` 한 번 실행한다. 새 설문 응답 생성 불필요. 실제 원본 전체 재집계 및 전송 후 관리자 화면의 수집·집계·전송 시각과 수치를 대조한다.
8. 실제 실패 코드, Q45 검수, 미등록 보기, 학교매칭, 승인 근거를 확인한다. 최종 공개는 별도 학교별·레벨별 승인으로만 수행한다.

## 차단 조건
서버 사전 검증 실패, Q45 이력 미확인, 원본·집계 건수 불일치, 새 수신 기록 미확인, 개인정보 심사 미완료 중 하나라도 남으면 공개 완료로 선언하지 않는다.
