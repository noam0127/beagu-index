# 2026-11-20 전국 학교별 문항 결과 2차 복구 감사

## 범위
- 대상: 2023~2025년 `beagu_edited_school_rows` 중 `beagu_school_question_aggregates_v2`에 승인 문항 집계가 없던 453개 학교·연도 기록.
- 검증 원천: 사용자 소유 `raw_data : 배구지수 시즌2 (2024)`, `raw_data : 배구지수 시즌3 (2025)` 및 운영 Supabase 공식 학교 명부.
- 신규 원본 응답은 **시도 + 학교명 + 교육지원청**을 정규화하여 세 필드가 일치하고 학교 ID가 유일할 때만 연결. 시도·학교명만 같고 교육지원청이 달랐던 사례는 제외.

## 복구 결과
| 연도 | 기존 누락 | 3요소 확인 후보 | 신규 집계 학교 | 새로 연결된 최다 선택값 | 원본 1건 학교 |
|---|---:|---:|---:|---:|---:|
| 2023 | 1 | 0 | 0 | 0 | 0 |
| 2024 | 313 | 40 | **39** | **407** | 19 |
| 2025 | 139 | 13 | **13** | **567** | 10 |
| **합계** | **453** | **53** | **52** | **974** | **29** |

- 2024년 원본에는 폐쇄형 응답이 1~6의 번호로 기록되어 있어, `js/historical-questionnaire-choices.js`에 보존된 검증된 원래 보기와 대응시켰다. 원래 보기 미확인 문항 Q03과 Q12의 확인되지 않은 3번 선택지는 보류.
- 2025년 문항 Q01,Q02,Q05~Q29,Q31~Q50은 원본 보기와 `js/2025-observed-choices.js` 및 검증된 Q31~Q50 선택지 목록을 정확히 대조했다. 원문 불일치·공란·동률은 제외했다.
- 2024년 세 필드가 일치한 후보 1개교는 검증된 단독 최다 선택을 산출할 수 없어 보류했다.
- 본 표는 **학교별 최다 선택지를 재구성한 개수**이며 개별 응답 건수·응답 행·선택지 조합을 외부로 보내지 않는다.

### 2025년 복수선택 보충
- `beagu_school_question_modes_supplement_v1`에 Q03 2개, Q04 1개, Q30 5개, 합계 **8개 검증된 단독 최다 선택지** 추가.
- 쉼표는 괄호 바깥에 있을 때만 선택지 분리자로 처리하고, 원본에서 검증된 보기 하나만 단독 최다일 때 저장.
- 새로 생성한 2025년 상위 집계의 `source_rows`와 보충의 `valid_rows`가 일치하는 범위 안에 있는지 확인했다.

## 운영 DB 적용
- `public.beagu_school_question_aggregates_v2`: 기존 7,350개 → **7,402개**.
- 신규 집계 행 52개에 문항 최다 선택지 총 974개 저장. 응답자 원문·타임스탬프·성명·응답조합은 저장하지 않았고 공개 응답에는 `roundedDistribution`이나 건수가 포함되지 않는다.
- 운영 `beagu-level-api` **v36**이 해당 테이블과 복수선택 보충 테이블을 읽는지 직접 확인했다. 별도 함수 코드 변경은 필요하지 않았다.
- 두 테이블 모두 RLS 활성화, `anon`/`authenticated` 직접 SELECT 권한 없음.
- 원본 1건인 신규 집계 29개교를 포함했으나, **운영자 지시와 원본 1건은 개별 응답자의 동의 및 재식별 위험 검토를 대체하지 못한다**.

## 남은 데이터
- 현재 편집본 대비 승인된 문항 집계 미연결: **401건** — 2023년 1건, 2024년 274건, 2025년 126건.
- 다수는 원본 설문 파일에서 학교명까지 일치하는 응답이 확인되지 않거나, 동명이교·교육지원청이 충돌한다. 편집본의 숫자형 수치는 최다 선택 보기의 정확한 분포를 의미하지 않으므로 역추정하여 채우지 않았다.
- 나머지 401건을 해결하려면 원본 설문 시트의 지역·학교명 별칭 목록과 교육지원청을 재검증하고, 필요하면 별도의 승인된 자료를 확보해야 한다.
- 2023 Q11~Q14, 2024 Q03, 2025 원문 보기가 불완전한 응답은 이번 복구에서 임의로 개방하지 않았다.
- 2026년의 72시간 유예·검수 규칙 및 원본 데이터는 변경하지 않았다.

## 검증
- 신규 2024년 39개교/407문항, 2025년 13개교/567문항: SQL 재조회 일치.
- 추가 복수선택 8건, `valid_rows <= source_rows` 위반 0건.
- 공개 API가 개별 응답과 건수를 전송하지 않는 것을 코드에서 확인.
- 운영 DB 조회 완료. 실제 로그인 세션을 사용한 브라우저 종단 테스트는 아직 완료하지 못했다.
