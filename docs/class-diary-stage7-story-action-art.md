**주의:** 이 표는 등장 회차를 근거로 한 원화 **제작 후보**다. 실제 본편의 모든 경로에서 인물 사진이 항상 표시되는 것은 아니다. 기존 `DEFAULTS` 69회차 순환 배정만으로 새 원화가 필요한 것은 아니다.

## 만든 이미지
- 차도겸의 파란 실뜨기 독립 RGBA 컷 한 장 (1086×1448px, PNG 및 WebP), 로컬 검수용.
- 기존 게임 실사 원본과 나란히 비교한 검수 시트.
- 기존 실사 기준 얼굴과 일치하지 않아 **최종 사용 불가**. 얼굴이 완전 동일한 원화라고 표기하지 않는다.
- 바이너리는 현재 ChatGPT 대화 다운로드 ZIP에만 있고 GitHub PR에는 올리지 않았다.

## 필수 검수
1. 원본 얼굴, 눈·코·입·헤어라인, 체형 동일.
2. 양손·손가락·어깨, 소품 모양 온전.
3. 도겸의 실은 복선 기준 **파란색** (기존 원본은 밝은 분홍·붉은색 계열).
4. 한현우는 『논어』, 서지윤은 4현 베이스기타(일반 통기타와 다름).
5. 백태오는 공을 손에 들고 있는 장면과 공을 가방에 넣는 장면을 구별.
6. 모바일 실화면에서 원화 잘림, alpha edge artifact 점검.
7. 누군가 새 사진을 '승인'하기 전까지 게임 HTML/JS/CSS 및 운영 자료 미변경.

## 파이프라인
- GitHub Actions는 위 6종 명세를 JSON + CSV로 검수 아티팩트에 포함한다.
- 테스트는 설명 문구만 검사하는 것이 아니라, 동료 사건 모듈의 실제 episode string과 고정 에셋 SHA도 대조한다.
- PR #156은 드래프트로 유지, `main` 병합·운영 배포 금지.
