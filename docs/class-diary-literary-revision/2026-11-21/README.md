## 사용 기준
- **프롤로그:** 동료의 1인칭 시점, 주인공이 모르는 내면은 묘사하지 않는다.
- **1~36화:** 주인공 ‘나’의 1인칭 시점.
- **확정 시대·장소:** 2027년 3~7월, 3학년 5반 장미반, 1층 복도 끝 창고 개조 교실, 옆 매화반(1학년 1반).
- **선택:** 매 화 행동 선택 3개와 학급일지 3개 중 1개.
- **연출:** 행동·효과음·화면 전환은 자막에 표시하지 않는 내부 지시로 분리한다.
