4. [3화 — 복합기가 삼킨 오전](03-copier-morning.md): **문학적 2차 퇴고본**. 과도한 농담·설명 독백을 덜고, 실제 수업 선택에 따라 장미반의 위치와 동료 관계가 다르게 드러나도록 재작성. 3개 행동 선택과 학급일지 선택 3개 유지.
5. [4화 — 동생 손을 잡는 아이](04-siblings-next-door.md): **집필·문학적 2차 퇴고본**. 3학년 도하와 1학년 다희의 남매 관계, 학생 자기결정권, 중국어도 사용하는 가정의 일상, 별도 지원 수업을 비낙인적으로 서술. 행동 선택 3개·결과 3개·학급일지 3개, 35화 재회수 복선 포함.
6. [5화 — 전원 동의라는 말](05-unanimous-consent.md): **집필·문학적 2차 퇴고본**. 줄서기·자리배치 학급회의, 교사의 조급한 '전원 동의' 기록, 박수현·한현우의 현실적인 질문, 3개 행동 선택별 정정 및 29·34화의 상이한 복선 회수 명세, 학급일지 3개 포함.

## 사용 기준
- **프롤로그:** 동료의 1인칭 시점, 주인공이 모르는 내면은 묘사하지 않는다.
- **1~36화:** 주인공 ‘나’의 1인칭 시점.
- **확정 시대·장소:** 2027년 3~7월, 3학년 5반 장미반, 1층 복도 끝 창고 개조 교실, 옆 매화반(1학년 1반).
- **선택:** 매 화 행동 선택 3개와 학급일지 3개 중 1개.
- **연출:** 행동·효과음·화면 전환은 자막에 표시하지 않는 내부 지시로 분리한다.
