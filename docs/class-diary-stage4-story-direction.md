# 『나의 OO한 학급일지』 4단계 1차 — 진행 기록 미저장 및 서사 연출 고도화

기준일: 2026-11-19 / 4단계 1차. 배포 대상: baeguindex.com / GitHub Pages.

## 1. 게임 기록은 저장하지 않는다

- 사용자가 요청한 정책으로, 주인공 설정·선택·진행·엔딩·점수 등을 localStorage, sessionStorage, IndexedDB, 데이터베이스, 서버 API에 저장하지 않는다.
- 이전 버전의 저장 동의 체크박스, 저장/불러오기, 완료 기록, 로컬 순위 등을 게임 화면에서 삭제했다.
- 예전 로컬 저장 데이터가 남았을 수 있어 게임 페이지에 들어오면 `beagu-class-diary-save-v1:*`와 `beagu-class-diary-history-v1` 키만 골라 삭제한다. 다른 배구지수 서비스의 저장 정보는 삭제하지 않는다.
- 페이지를 새로고침하거나 떠나는 순간 플레이 메모리 상태는 사라진다. 화면에 상시 안내: **'기록은 저장되지 않습니다. 페이지를 나가거나 새로고침하면 진행 상황과 결과가 모두 사라집니다.'**
- 레벨2 접근 인증을 위해 기존 사이트에서 만든 `sessionStorage`의 인증 세션 값은 읽기만 한다. 이는 게임 플레이 저장 데이터가 아니며, 이 게임은 인증 세션을 새로 저장하지 않는다.
- 레벨2 API에 보내는 값은 조회할 학교 ID와 기존 인증 세션뿐이다. 게임 선택·프로필·점수는 API로 보내지 않는다.
- 3단계에서 노출하던 게임 엔진의 `createSnapshot` 및 `restore` API도 제거했다.

## 2. 전날의 선택이 다음 날 이야기로 이어진다

- `js/class-diary-director-v1.js`를 신규 개발하고 기존 `js/class-diary-play-v1.js` 엔진 위에 연결.
- 7일 × 3개 선택지 = 가능한 전체 2,187개 선택 경로에서 전날의 선택을 반영한 문학적 연결 문단이 출력된다.
- 첫날 업무분장→둘째 날 협의, 둘째 날 발언→셋째 날 학생자치, 셋째 날 학급 규칙→넷째 날 갈등 중재, 넷째 날 상담→다섯째 날 관계, 다섯째 날 회식 선택→토요일 개인의 시간, 토요일 연락 방식→일요일 회고로 이어진다.
- 기존 점수를 사용하는 관계 문단도 추가했다. 신뢰가 쌓인 경우/거리감이 남은 경우/휴식이 필요한 경우의 서사가 달라진다.
- 결과 장면과 엔딩에는 관계, 학생의 사회적 자리, 교사의 휴식에 관한 회고를 추가한다.
- 인물의 성별이나 플레이어 MBTI가 실제 교직원의 성격·평판·업무 배정을 단정하지 않으며 점수에서 불이익을 주지 않는다.

## 3. 장면별 시각 연출

- `teacher-class-diary-play.html`의 일곱 장에 서로 다른 CSS 색면/추상 교실 풍경, 상징 문양, 인물 아바타 및 인물 성격 소개를 연결했다. 외부 사진이나 실제 교직원 초상은 사용하지 않는다.
- 동료는 성인 가상인물 지윤·현우 또는 우정 중심 동학년 교사이다. 해당 선택은 점수 차별을 만들지 않는다.
- 화면의 학교정보 보조 설명은 검토 승인된 연도별 공식 수치와 공식 주소에서 확인한 행정 구역만 사용한다. 최신 현황으로 오해되지 않도록 출처 기준연도 표시.
- 장면의 가상 대사와 실제 과거 조사 통계는 혼동되지 않도록 별도 문구로 안내한다.
- `prefers-reduced-motion` 설정을 존중해 화면 전환 애니메이션을 끌 수 있다.

## 4. 구현·검증 범위

- JS 모듈: `js/class-diary-director-v1.js`.
- 자동 검사: `scripts/test-class-diary-director.cjs` (전체 2,187가지 루트와 7일 후속문단, 공식정보 승인 검사), `scripts/test-class-diary-play.cjs` (5종 엔딩 도달성), `scripts/test-class-diary-play-page.cjs` (화면 JS 문법·화면 연결·저장 기능 미사용).
- 기존 세계 데이터 및 설문 공개 API와 독립적으로 작동하며, 데이터베이스/기존 게임/레벨 권한 설계를 변경하지 않는다.

## 5. 4단계의 남은 범위

- 실사용 레벨2 계정으로 모바일/PC 브라우저에서 7일 전체를 직접 누르며 E2E 확인.
- 두 인물의 고유한 시선과 중장기 목표, 추가 배경 사건과 장면 내 대화 선택을 더 풍부하게 구성.
- 화면 읽기 편의, 오탈자, 단락 호흡, 감정 표현을 원고 수준으로 교정하고 자연스러운 한국 소설 문체를 발전.
- 저장 및 순위표는 구현하지 않으며, 재도입은 별도 사용자 요청이 있을 때에만 검토.

## 6. 참여 및 개인정보 경계

실제 학교의 과거 통계는 소설의 창작 재료이고, 실제 동료·학생·보호자의 언행에 대한 사실 주장이 아니다. 미승인 2026년 응답, 개인·학교 단위 고위험 조사 응답, 학생 관련 민감 사례는 게임에 포함하지 않는다.
