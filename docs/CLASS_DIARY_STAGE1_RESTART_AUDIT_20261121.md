## 2. 최신 핵심 이야기의 기준안과 충돌

현행 5인물 기준 문서의 인물은 **서지윤(베이스기타·현장 경험), 한현우(『논어』·말과 예의), 윤민서(중식 요리·자료와 이론), 차도겸(실뜨기·동의와 선택권), 백태오(배구·팀의 협력)**. 주인공은 교감의 긴급 연락을 받아 3학년 장미반에 배치되는 기간제 담임이다. 본편은 주인공 1인칭, 프롤로그는 선택한 동료 1인칭으로 구성한다.

주요 학생은 도윤·서아·하린·지후·준혁·윤아·민재이며, **허구 인물**이어야 한다. 학급회의·규칙 재검토, 물가와 학급경제, 교실 이탈 안전, 복도 사고와 다른 목격, 관계 배제와 사과 수용 거부, 공개수업, 기간제 계약 종료가 36화의 반복·회수 축이다.
