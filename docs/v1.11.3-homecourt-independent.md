# v1.11.3 홈코트 독립 후보
현재 운영 v1.11.4 기준. 기존 인증·권한·추천·계정 유지. 포지션닉 서버 응답만 추가하고 사설 작성자 UID 미노출. 댓글의 시간순 첫 등장으로 중복 번호 부여; 숨김·삭제 상태의 기존 댓글은 순서 유지에만 사용. 기존 행의 물리 삭제 또는 늦게 커밋되는 이전 시각 댓글은 번호를 바꿀 수 있으므로 엄격한 영구 고정은 추가 검증 필요. 계정·관제탑 병합 금지. 운영 적용 전 서버/브라우저 검증 및 API 호환 확인 필요.

추가: 공통 메뉴 홈코트·라커룸 표시를 기존 권한 스크립트에서 적용. 전체 세계관 용어 교체와 영구 배정 DB는 시간 제한으로 보류. 후보 버전은 운영 등록용으로 표시하지 않음.
