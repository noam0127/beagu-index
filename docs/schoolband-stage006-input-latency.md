# 『난감한 스쿨밴드』 006/030 — 오입력·동시노트·입력 지연 보정

진행일: 2026-11-22 KST. **공식 범위:** 사용자가 제공한 30단계 원본의 006/030(원본 024~027). 시험 브랜치 `schoolband-playtest`에만 적용. 운영 `main`, `baeguindex.com`, 운영 Supabase API·DB 수정 금지.

## 1. 실제 변경 사항

- **레인 격리:** 타격 시 차트에서 해당 레인만 검색하는 순수 함수 `selectPendingNoteIndex(notes, lane, correctedTime, tierIndex)`를 추가. `done`이 아닌 해당 레인의 노트 중 판정 범위 안에서 시간 차이가 가장 작은 노트만 선택한다. 동일 거리는 먼저 오는 노트를 선택한다. 다른 레인의 노트는 선택하거나 변경하지 않는다.
- **같은 시각 동시노트:** 각 타격은 `chart[chosen]` 하나만 `done=true`로 전환하고 점수·콤보를 독립 반영한다. 다른 레인의 같은 시각 노트가 사라지거나 중복 판정되지 않도록 한다.
- **오프셋 UI:** 게임 아래 접이식 '판정 보정' 설정에 `-150~+150 ms`, 5ms 간격 슬라이더, 현재 값, 저장, 초기화 버튼과 안내문을 추가. 설정값은 이 브라우저의 `localStorage['nangam-band-input-offset-ms-v1']`에 **정수 1개만** 저장된다. 다른 사용자·학교 식별자나 원시 터치 로그를 저장하지 않는다.
- **부호와 계산:** `correctedInputTime(songTime, offsetMs) = songTime - offsetMs/1000`. **+120ms**는 실제보다 입력이 120ms 늦게 도착할 때 늦은 타격을 120ms 앞당겨 판정한다. **−120ms**는 반대로 이르게 입력되는 경우를 보정한다. 기본값은 0이며, 입력이 실제로 지연되는지는 사용자가 직접 비교해야 한다.
- **판정·MISS 일관성:** `hit()`와 `animate()`의 MISS 마감 모두 보정된 오디오 시간축을 사용한다. 그렇지 않으면 +오프셋 상태에서 노트가 먼저 MISS로 소실되어 늦은 타격이 영원히 맞지 않는 결함이 생긴다. 소리 재생과 화면의 노트 이동은 **기존 AudioContext.currentTime**에 계속 동기화하고 오프셋으로 곡/리듬·음성을 바꾸지 않는다.
- **안전 범위:** 잘못되거나 임의 조작된 저장값은 0으로 복구하거나 허용 범위 `±150 ms`에 제한하고 5ms 단위로 정렬한다. 노래 진행 중에는 슬라이더 및 초기화 버튼을 잠가 게임 중 판정 규칙이 급변하지 않도록 한다.
- **동작/학습 안내:** 안내는 자동 센서 측정 기능처럼 표현하지 않는다. 여러 기기의 오디오 **출력 지연과 입력 이벤트 지연의 체감 차이를 함께 보정하는 수동 설정**으로만 설명한다.
