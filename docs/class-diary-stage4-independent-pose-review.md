### 시각 검수 기준
- 투명 RGBA PNG와 WebP 준비, 3:4 프레임 유지.
- 차도겸 1086×1448, 백태오 1536×2048, 서지윤 1086×1448. 1536으로 크기만 늘리는 것을 네이티브 화질로 주장하지 않는다.
- 새 원화의 표정·의상·소품은 적합한 편이나 **기존 게임 얼굴과의 일치가 검증되지 않음**. 인물 동일성 규칙에 따라 **현재 단계에서 운영에 연결하지 않음**.
- 실뜨기 줄의 연결, 손가락 개수, 배구공과 팔의 접촉, 머리카락·의상 투명 경계를 수동 확인해야 함.
- 비교 시트는 원본 게임 프레임과 새 초안을 인물별로 위아래 배치.
- 이미지 생성 과정에서 4인 합본 또는 텍스트 시트가 나온 결과는 불합격으로 배제.
