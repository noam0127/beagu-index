# 남성 캐릭터 자연스러운 8포즈 (2026-11-20)
이 작업은 실제 없는 교직원과 학생이 등장하는 36화 비주얼 노벨의 남성 성인 교사 3명만 변경한다.

- 한현우: 차분함, 미소, 머쓱함, 설명, 고민, 피로, 경청, 수첩(4열×2행).
- 차도겸: 인사, 실뜨기, 준비, 경청, 생각, 실뜨기 시범, 미소, 수줍음(8열×1행).
- 백태오: 인사, 배구공, 설명, 기록, 머쓱함, 고민, 경청, 휴식(8열×1행).
- WebP 이미지 크기 약 70~84KB/파일, 배경 분리는 자동 작업으로 가장자리 아티팩트 수동 확인 필요.
- 프롤로그 서지윤·윤민서 등 여성 캐릭터는 수정하지 않는다.
- 36화 본편 외 7일 체험판, 학교 데이터, 레벨 인증, 선택지, 저장/개인정보 API는 변경하지 않는다.
- 인물의 구체적 맥락에 맞춘 포즈 매핑을 수행하며, 작은 화면에는 대사창을 가리지 않도록 높이/하단 여백을 제한한다.
- 성인 인물 모두 완전한 허구 이미지이며 실존 인물이나 특정 배우를 재현하지 않는다.
