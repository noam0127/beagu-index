## 실제 변경 내용

### 1. 한 곡 안의 자동 반주와 사용자 연주 분리

`autoPartsAtStep(step,selected)`는 원본 28음 선율 `MELODY_BY_STEP`과 8마디 반주를 108 BPM 16분음표 시간축으로 결정한다. 선택한 악기 파트는 자동 반주에서 항상 제외한다. 자동 반주에는 멜로디와 **선택하지 않은 3악기**가 결합된다. 이전 자동 반주 리듬(드럼 8분 단위, 베이스 4분 단위, 기타/키보드 2박 간격)은 유지하고, 이제 드럼도 `voice("drums", ... , "auto")`를 통과해 다른 자동 악기처럼 로그가 기록되게 했다.

`voice(inst, beat, when, lane, source="auto")`는 실제 성공한 `hit()`에서만 `"hit"` 소스로 호출된다. `animate()`에서 MISS로 변한 노트는 `"miss"` 이벤트(가청=false)로 기록하고 **사용자가 선택한 악기 소리를 재생하지 않는다**. 자동 반주는 정해진 박자대로 계속 진행할 수 있다.

### 2. 구별 가능한 기타/드럼 음색

| 악기 | 레인 | Web Audio 기반 음향 구조 | 자동 반주와의 구분 |
|---|---|---|---|
| 일렉기타 | 리프(D) | 단음 sawtooth 0.135초, 강한 짧은 어택 | 손으로 노트를 맞혀야 연주 |
| 일렉기타 | 파워코드(F) | sawtooth 기반음·완전5도 + 낮은 삼각파 옥타브 보강(3발음) | 멀티 음정의 묵직한 화음 |
| 일렉기타 | 업스트럼(J) | sawtooth 3음, 발음 시작 시차 0ms/17ms/34ms | 줄을 위로 쓸어 올리는 짧은 시차 |
| 일렉기타 | 고음 리프(K) | 짧은 sawtooth + 밝은 삼각파 옥타브 | 고음 악센트 |
| 드럼 | 킥(D) | sine 135Hz→45Hz, 0.17초 하강 어택 | 낮은 진동 |
| 드럼 | 스네어(F) | 삼각파 본음 + 필터 고역 잡음 | 짧은 스냅 |
| 드럼 | 하이햇(J) | 4.2kHz highpass 노이즈만, 0.045초 | 고역 리듬 |
| 드럼 | 탐(K) | triangle 235Hz→96Hz, 0.23초 피치 다운 | 중저음 잔향 |

기존 베이스의 3개 레인 triangle, 키보드 5개 레인 sine/화음 구조와 창작곡 28음 멜로디의 원음정·원박자는 유지한다. 음색을 구분한다는 뜻은 파형·시차 및 대역 차이를 코드로 구현한 것이고, 실제 청음상 유사성·기기별 음색까지 입증했다는 뜻이 아니다.

### 3. 실제 브라우저에서 추적 가능한 메모리 오디오 이벤트

`logAudioEvent(source,part,lane,when,detail)`는 합주를 구조화된 이벤트 형태로 기록한다.

- `source`: `auto`, `hit`, `miss`
- `part`: `melody`, `guitar`, `drums`, `bass`, `keys`
- `lane`: 실제 레인, 멜로디는 -1
- `when`: `AudioContext.currentTime` 기준 초 (소수 6자리 반올림)
- `detail`: 악기별 레인 이름 또는 MISS/원곡 메모
- `audible`: 실제 음소거 상태에 따른 이벤트 재생 여부. MISS는 항상 false.

API `getAudioEvents()`는 이벤트 사본을 반환, `getAudioPlan(step)`은 원본 선율의 자동 반주 악기 목록을 반환한다. 최대 384개 이벤트만 보존해 무한 누적을 피한다. 로그는 **브라우저 메모리에만** 있고 Supabase/학교명/사용자 식별자/연습 점수 등을 전송하지 않는다. 실제 Web Audio 노드 시작 여부는 CI에서 직접 별도 트레이싱한다. 이 이벤트는 내부 엔진 테스트·디버깅용이고 일반 사용자에게 공개 순위/성적표로 제공하지 않는다.
