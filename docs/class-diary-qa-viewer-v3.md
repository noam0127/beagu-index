# 『나의 OO한 학급일지』 36화 이미지 대조 검수 (V3)

## 목적
기존 게임에 이미 사용되는 남성 교사 3명 × 8포즈 및 서지윤의 기준 사진을 바꾸지 않고, 생성된 25개 **검수용 투명화 이미지**를 같은 장면 안에서 확인합니다. 36화 본편의 포즈 배정은 `js/class-diary-male-natural-v2.js`에 맞추며, 새로운 연애·호감도·시나리오 기능은 만들지 않습니다.

## 실행
1. PR #156의 GitHub Actions **Class Diary original-photo cutout QA** 성공 실행으로 이동합니다.
2. 아티팩트 `class-diary-original-identity-cutouts-v2-DRAFT`를 내려받아 압축을 풉니다.
3. `preview.html`을 브라우저에서 엽니다. `source_atlases/`, `hyunwoo/`, `dogyeom/`, `taeo/`, `jiyoon/` 디렉터리를 같은 위치에 유지합니다.
4. 인물→회차→포즈, 선택 후 반응(1/2/3), 데스크톱/모바일, 배경(학교/체커보드/어두운색)을 바꾸며 원본과 투명화 결과를 비교합니다.
5. 손가락, 실뜨기 줄, 배구공, 머리카락, 옷 소매, 배경 잔재, 원본과의 얼굴 차이를 직접 확인합니다.
6. 필요한 경우 검수 메모를 작성하고 **검수 기록 JSON 저장**을 누릅니다. 페이지는 데이터를 서버에 전송하거나 브라우저 저장소에 남기지 않습니다.

## 파일 상태
- 기술 검수 사용 후보 5컷: 한현우 neutral/smile/shy/explaining/notebook — **사람의 최종 승인은 아직 없음**
- 보정 필요 13컷, 현 상태 제외 7컷. 차도겸·백태오의 8열 원본에서 이미 잘린 양팔·어깨는 자동 마스크만으로 복원할 수 없습니다.
- 이 이미지가 1536×2048로 저장되더라도 원본 프레임의 실제 세밀도는 증가하지 않습니다.
- 서지윤 원본의 외모와 보라색 부분 염색에 차이가 있으므로 최신 외형 승인은 보류합니다.

## 운영 안전
- 게임의 원래 8포즈 사진 WebP와 여성 배우 이미지를 변경하지 않습니다.
- 원본에 없는 얼굴을 생성한 독립 초안은 기존 인물로 자동 승인하지 않습니다.
- `preview.html`은 아티팩트 내부의 독립 검수 화면으로, 운영 게임 HTML에 삽입하지 않습니다.
- `main`, 실제 배포 사이트, 로그인/레벨/학생 자료/시나리오 저장 기능에 영향이 없습니다.
- GitHub PR #156은 드래프트로 유지합니다.
